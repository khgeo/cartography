# មេរៀនទី៦៖ អថេរមើលឃើញ និងការរចនានិមិត្តសញ្ញា

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៦ ក្នុងចំណោម ១៥

ផែនទីនិយាយជាមួយភ្នែក។ ភាសារបស់វាគឺ **អថេរមើលឃើញ (Visual variables)**៖ ទំហំ តម្លៃពន្លឺ ពណ៌ រាង ទិសដៅ និងវាយនភាព។ ការជ្រើសអថេរដែលសមនឹងប្រភេទទិន្នន័យ ធ្វើឲ្យអ្នកអានយល់ភ្លាមៗ។ ការជ្រើសខុស ធ្វើឲ្យអ្នកអានយល់ខុស ទោះទិន្នន័យត្រឹមត្រូវ។

មេរៀននេះណែនាំអថេរមើលឃើញរបស់ Bertin ការរចនានិមិត្តសញ្ញាចំណុច បន្ទាត់ ផ្ទៃ និងឋានានុក្រមមើលឃើញ។

## ៦.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. រាយអថេរមើលឃើញ និងលក្ខណៈរបស់ពួកវា។
2. ផ្គូផ្គងអថេរមើលឃើញជាមួយកម្រិតរង្វាស់ (Nominal Ordinal Quantitative)។
3. រចនានិមិត្តសញ្ញាចំណុច បន្ទាត់ និងផ្ទៃ ដែលច្បាស់ និងអានងាយ។
4. ពន្យល់ឋានានុក្រមមើលឃើញ និងរបៀបបង្កើតវា។
5. វិនិច្ឆ័យនិមិត្តសញ្ញាក្នុងផែនទីពិត ហើយស្នើការកែ។

### ចំណេះដឹងមុនត្រូវមាន

- ខ្លឹមសារ[មេរៀនទី១](lesson-01.md)៖ ការធ្វើនិមិត្តសញ្ញា និងគំរូទំនាក់ទំនងផែនទី។
- កម្រិតរង្វាស់ (Nominal Ordinal Interval Ratio) ពី[មេរៀនទី៤ សៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/lessons/lesson-04/)។

## ៦.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីសាលារៀនដែលបំភាន់

មន្ត្រីម្នាក់ធ្វើផែនទីសាលារៀនក្នុងខេត្ត។ គាត់ប្រើ **រង្វង់ធំតូច** តំណាង **ប្រភេទសាលា**៖ រង្វង់ធំសម្រាប់វិទ្យាល័យ រង្វង់តូចសម្រាប់សាលាបឋមសិក្សា។

អ្នកអានយល់ថា រង្វង់ធំ = សាលាសំខាន់ជាង ឬមានសិស្សច្រើនជាង។ តាមពិត សាលាបឋមសិក្សាមួយចំនួនមានសិស្សច្រើនជាងវិទ្យាល័យតូចៗ។ ផែនទីនិយាយរឿងមួយ ទិន្នន័យនិយាយរឿងមួយទៀត។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- អថេរមើលឃើញណាដែលប្រាប់ «ច្រើនជាង» និងណាដែលប្រាប់តែ «ខុសគ្នា»?
- តើត្រូវជ្រើសអថេរយ៉ាងណាតាមប្រភេទទិន្នន័យ?
- តើធ្វើយ៉ាងណាឲ្យធាតុសំខាន់លេចធ្លោលើផែនទី?

## ៦.៣. ទ្រឹស្ដីស្នូល

### ៦.៣.១. អថេរមើលឃើញ

អ្នកផែនទីវិទ្យាបារាំង **Jacques Bertin** បានរៀបរាប់អថេរមើលឃើញ ដែលអាចប្រើតំណាងទិន្នន័យ៖

| អថេរ | ឧទាហរណ៍ | អ្វីដែលភ្នែកអានបាន |
|---|---|---|
| **ទីតាំង** | កន្លែងដែលសញ្ញាស្ថិតនៅ | ទាំងអស់ (ជាមូលដ្ឋាននៃផែនទី) |
| **ទំហំ** | រង្វង់ធំ ↔ តូច | លំដាប់ និងសមាមាត្រ |
| **តម្លៃពន្លឺ** | ស្រាល ↔ ដិត | លំដាប់ |
| **ពណ៌** | ក្រហម ខៀវ បៃតង | ភាពខុសគ្នា (ប្រភេទ) |
| **រាង** | រង្វង់ ការ៉េ ត្រីកោណ | ភាពខុសគ្នា |
| **ទិសដៅ** | បន្ទាត់ទ្រេត ↔ ឈរ | ភាពខុសគ្នា (កម្រិតតិច) |
| **វាយនភាព** | ចំណុចក្រាស់ ↔ រង្គាស | លំដាប់ខ្លះ និងភាពខុសគ្នា |

### ៦.៣.២. ការរចនានិមិត្តសញ្ញាចំណុច បន្ទាត់ និងផ្ទៃ

| ធរណីមាត្រ | អថេរដែលប្រើញឹកញាប់ | ការអនុវត្តល្អ |
|---|---|---|
| **ចំណុច** | ទំហំ រាង ពណ៌ | សញ្ញារូបភាព (សាលា មន្ទីរពេទ្យ) ងាយចាំ · ទំហំអប្បបរមា ២ មម លើក្រដាស |
| **បន្ទាត់** | ទទឹង តម្លៃពន្លឺ ពណ៌ លំនាំ (ដាច់ៗ) | ថ្នាក់ផ្លូវតាមទទឹង · ទន្លេពណ៌ខៀវ · ព្រំដែនដាច់ៗ |
| **ផ្ទៃ** | តម្លៃពន្លឺ ពណ៌ វាយនភាព | ផ្ទៃពណ៌ស្រាល ដើម្បីកុំលាក់ធាតុផ្សេង |

ក្បួនជាក់ស្ដែង៖

- **ចំនួនថ្នាក់តិច**៖ ភ្នែកបែងចែកទំហំបានប្រហែល ៥ ដល់ ៧ ថ្នាក់ និងពណ៌ប្រភេទប្រហែល ៧ ដល់ ១២។
- **សញ្ញាស្រដៀងគ្នា = អត្ថន័យស្រដៀងគ្នា**៖ ទន្លេ ស្ទឹង និងប្រឡាយគួរមានពណ៌តែមួយ ខុសគ្នាតែទទឹង។
- **សញ្ញាសម្គាល់ផែនទីត្រូវត្រូវគ្នាបេះបិទ**ជាមួយផែនទី៖ ពណ៌ ទំហំ និងលំដាប់ដូចគ្នា។
- **សាកល្បងទំហំពិត**៖ សញ្ញាដែលច្បាស់លើអេក្រង់ ១០០% អាចមើលមិនឃើញលើក្រដាស A4។

### ៦.៣.៣. ទំហំសញ្ញាសមាមាត្រ

ពេលប្រើទំហំតំណាងបរិមាណ (ឧ. ចំនួនប្រជាជន) ភ្នែកអានផ្ទៃ មិនមែនកាំទេ។ ដូច្នេះត្រូវ **ធ្វើមាត្រដ្ឋានតាមផ្ទៃ**៖

> កាំ = k × √(តម្លៃ)

បើគុណកាំដោយផ្ទាល់នឹងតម្លៃ រង្វង់នៃតម្លៃ ៤ ដង នឹងមើលទៅធំជាង ១៦ ដង។ ការសិក្សាបានបង្ហាញថា អ្នកអានតែងប៉ាន់ស្មានទំហំរង្វង់ធំទាបជាងការពិត ដូច្នេះការធ្វើមាត្រដ្ឋានខ្លះកែតម្រូវបន្តិច (Flannery)។

និមិត្តសញ្ញាសមាមាត្រ និងផែនទីចំណុចដង់ស៊ីតេ នឹងសិក្សាលម្អិតក្នុង[មេរៀនទី១០](lesson-10.md)។

### ៦.៣.៤. ឋានានុក្រមមើលឃើញ

**ឋានានុក្រមមើលឃើញ (Visual hierarchy)** គឺជាលំដាប់ដែលភ្នែកមើលធាតុនានា។ ធាតុសំខាន់បំផុតត្រូវលេចធ្លោ ឯបរិបទត្រូវថយក្រោយ។

វិធីបង្កើតឋានានុក្រម៖

- **កម្រិតពណ៌ (Contrast)**៖ ធាតុសំខាន់ដិត ឯបរិបទស្រាល។
- **ទំហំ និងទទឹងបន្ទាត់**៖ ធាតុសំខាន់ធំជាង។
- **តំណែងលើក្រោម**៖ ចំណុចនៅលើ បន្ទាត់កណ្ដាល ផ្ទៃនៅក្រោម។
- **ពណ៌ឆ្អែត ធៀបនឹងពណ៌ស្លេក**៖ ពណ៌ឆ្អែតទាញភ្នែក។

### ៦.៣.៥. និមិត្តសញ្ញាក្នុង QGIS

| ប្រភេទ Symbology | ប្រើពេលណា |
|---|---|
| **Single Symbol** | ស្រទាប់បរិបទ (ព្រំដែន ទឹក ផ្លូវ) |
| **Categorized** | ទិន្នន័យប្រភេទ (Nominal) ដូចជា `SCHOOL_TYP` `Zone_Sch` |
| **Graduated** | ទិន្នន័យបរិមាណ ([មេរៀនទី៧](lesson-07.md) និង[មេរៀនទី៩](lesson-09.md)) |
| **Rule-based** | លក្ខខណ្ឌស្មុគស្មាញ ឬតាមមាត្រដ្ឋាន |
| **Data-defined override** | ទំហំ ឬពណ៌មកពីវាល (សញ្ញាសមាមាត្រ) |

លក្ខណៈពិសេសមានប្រយោជន៍៖ **Scale-dependent visibility** (បង្ហាញស្រទាប់តែនៅមាត្រដ្ឋានជាក់លាក់) និង **Draw effects** ដែលគួរប្រើដោយសន្សំសំចៃ។

## ៦.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ រចនាឡើងវិញនូវផែនទីសាលារៀន

យើងកែផែនទីក្នុងស្ថានភាពបើកមេរៀន ដែលមានទិន្នន័យពីរ៖ **ប្រភេទសាលា** (Nominal) និង **ចំនួនសិស្ស** (Quantitative)។

### ជំហានទី១៖ កំណត់ប្រភេទទិន្នន័យ

ប្រភេទសាលា = Nominal → ត្រូវការអថេរដែលបង្ហាញភាពខុសគ្នា៖ **ពណ៌** ឬ **រាង**។ ចំនួនសិស្ស = Quantitative → ត្រូវការ **ទំហំ**។

### ជំហានទី២៖ ជ្រើសនិមិត្តសញ្ញា

ប្រភេទសាលាតាម **រាង** (រង្វង់ = បឋមសិក្សា · ការ៉េ = អនុវិទ្យាល័យ · ត្រីកោណ = វិទ្យាល័យ) ហើយចំនួនសិស្សតាម **ទំហំ** ដោយកាំ = k × √(សិស្ស)។ ពណ៌រក្សាតែមួយ ដើម្បីកុំបន្ថែមអថេរដែលមិនចាំបាច់។

### ជំហានទី៣៖ បង្កើតឋានានុក្រម

ព្រំខេត្តពណ៌ប្រផេះស្ដើង · ផ្លូវជាតិពណ៌ត្នោតស្រាល · សាលាពណ៌ដិត នៅស្រទាប់លើគេ។

### ជំហានទី៤៖ សាកល្បង និងកែ

បោះពុម្ព A4 ហើយសួរមិត្តបីនាក់ថា «សញ្ញាធំមានន័យអ្វី?»។ បើពួកគេឆ្លើយថា «សាលាសំខាន់» ត្រូវកែសញ្ញាសម្គាល់ផែនទី ដោយបន្ថែមរង្វង់គំរូជាមួយលេខសិស្ស។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «បញ្ហានៃផែនទីដើម មិនមែនទិន្នន័យទេ ប៉ុន្តែការប្រើ «ទំហំ» សម្រាប់ទិន្នន័យប្រភេទ។ ការប្ដូរទៅ «រាង» សម្រាប់ប្រភេទ និង «ទំហំ» សម្រាប់ចំនួនសិស្ស ធ្វើឲ្យផែនទីនិយាយត្រូវនឹងទិន្នន័យ។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    ការរចនាល្អមិនធ្វើឲ្យទិន្នន័យខ្វះខាតក្លាយជាពេញលេញទេ។ បើទិន្នន័យចំនួនសិស្សមកពីឆ្នាំផ្សេងគ្នា ផែនទីនៅតែបំភាន់ ទោះនិមិត្តសញ្ញាត្រឹមត្រូវ។

## សិក្ខាសាលារូបភាព៖ សញ្ញាប្រាប់ប្រភេទ ឬបរិមាណ?

!!! note "រៀនដោយសាកល្បង · 35–45 នាទី"
    ផ្នែកនេះប្រើជំនួសពេលពិភាក្សា និងសកម្មភាពក្នុងម៉ោង 180 នាទី មិនមែនបន្ថែមលើម៉ោងទាំងអស់ទេ។ លេខដែលសរសេរថា «សន្មត» និងរូបប្រៀបធៀបថ្មីជាគំរូបង្រៀន មិនមែនស្ថិតិផ្លូវការ ឬផែនទីសម្រាប់នាវាចរណ៍ទេ។

### បញ្ហាដែលត្រូវដោះស្រាយ

ផែនទីសេវាសាធារណៈមានសាលា មណ្ឌលសុខភាព និងផ្សារ។ ផែនទីមួយទៀតបង្ហាញចំនួនអ្នកប្រើសេវា។ តើគួរប្តូររាង ពណ៌ ឬទំហំ?

### ពន្យល់ឲ្យឃើញមូលហេតុ

ទិន្នន័យ nominal មានប្រភេទ ប៉ុន្តែគ្មានលំដាប់។ ប្រើ hue ឬ shape ដែលខុសគ្នាដោយមិនបង្កើតអារម្មណ៍ថាធំតូច។ ទិន្នន័យ ordinal មានលំដាប់ ប៉ុន្តែចន្លោះរវាងថ្នាក់មិនចាំបាច់ស្មើគ្នា។ ទំហំ និងពន្លឺអាចបង្ហាញលំដាប់បាន តែត្រូវប្រយ័ត្នការបកស្រាយជាសមាមាត្រ។

Visual hierarchy គឺការកំណត់អ្វីឲ្យអ្នកអានមើលឃើញមុន។ ផ្ទៃក្រោយពណ៌ស្រាល ផ្លូវរងស្តើង និងសញ្ញាប្រធានបទច្បាស់ អាចធ្វើឲ្យសំណួរសំខាន់អានបានលឿន។ សញ្ញាធំ និងពណ៌ឆ្អែតគ្រប់ស្រទាប់ធ្វើឲ្យគ្មានអ្វីលេចធ្លោ។

### គណនា និងសម្រេចចិត្តមួយជំហានម្តង

សន្មតថាសេវា A មានអ្នកប្រើ 100 នាក់ និង B មាន 400 នាក់។ បើប្រើរង្វង់សមាមាត្រ ផ្ទៃ B ត្រូវធំ 4 ដង ប៉ុន្តែកាំត្រូវធំតែ 2 ដង។ បើគ្រាន់តែបង្ហាញប្រភេទ A និង B កុំប្រើរង្វង់ទំហំ 4 និង 8 មម ព្រោះអ្នកអានអាចយល់ថា B មានសារៈសំខាន់ ឬបរិមាណច្រើនជាង។

### ពិសោធន៍ដោយមានសំណួរណែនាំ

1. ជ្រើសទិន្នន័យប្រភេទក្នុងពិសោធន៍ visual variables ហើយប្តូររវាងរាង ទំហំ និងពណ៌។
2. ប្តូរទៅបរិមាណ ហើយកត់អថេរដែលអាចបង្ហាញច្រើន/តិចបាន។
3. មើលរូបប្រៀបធៀបដោយបិទភ្នែកបន្តិច ហើយបើកឡើងវិញ៖ អ្វីដែលមើលឃើញមុន?

| សាកល្បង | ការព្យាករណ៍មុនចុច | អ្វីដែលឃើញ | មូលហេតុ |
|---|---|---|---|
| លក្ខខណ្ឌដើម | សរសេរការរំពឹង | កត់តម្លៃ/លំនាំ | ភ្ជាប់ទៅគោលគំនិត |
| ប្តូរអថេរមួយ | ព្យាករណ៍ម្តងទៀត | ប្រៀបធៀបនឹងដើម | ពន្យល់ដោយភស្តុតាង |

### បញ្ហាប្រឈមតូច និងការផ្ទេរទៅ QGIS

**បញ្ហាប្រឈម៖** ធ្វើ Legend សម្រាប់ប្រភេទសេវា 3 និងកម្រិតចំនួនអ្នកប្រើ 3។ សាកល្បងជាមួយមិត្តម្នាក់ដោយមិនពន្យល់ ហើយកត់ការបកស្រាយរបស់គាត់។

**QGIS៖** ប្រើ Categorized លើប្រភេទសេវា និង Graduated លើបរិមាណ។ កំណត់ symbol size ជាមមសម្រាប់សញ្ញាដែលត្រូវមានទំហំថេរនៅលើក្រដាស។ ពិនិត្យនៅមាត្រដ្ឋានគោលដៅ មុន Export។

**លទ្ធផលត្រូវប្រគល់៖** រូបភាពមុន/ក្រោយមួយគូ តារាងតម្លៃ ឬការកំណត់ដែលបានប្តូរ និងការពន្យល់ 3–5 ប្រយោគ។ ពិនិត្យថាអ្នកអានម្នាក់ទៀតអាចធ្វើការគណនាឡើងវិញបាន។ បន្តទៅ [លំហាត់ QGIS 6](../workbook/lab-06.md) សម្រាប់ការអនុវត្តពេញលេញ។

    និស្សិតធ្វើលំហាត់នេះ **ដោយខ្លួនឯង** នៅក្រៅម៉ោងរៀន។

## ៦.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «ពណ៌ច្រើន ធ្វើឲ្យផែនទីស្អាតជាង»**
ពណ៌ច្រើនពេកបំបាត់ឋានានុក្រម។ ប្រើពណ៌តិច ហើយឲ្យវាមានន័យ។

**២. «ទំហំសញ្ញាគួរគុណនឹងតម្លៃដោយផ្ទាល់»**
ភ្នែកអានផ្ទៃ។ កាំត្រូវគុណនឹងឫសការ៉េនៃតម្លៃ។

**៣. «អថេរច្រើនក្នុងសញ្ញាតែមួយ ផ្ដល់ព័ត៌មានច្រើនជាង»**
ទំហំ + ពណ៌ + រាងក្នុងសញ្ញាតែមួយ ធ្វើឲ្យអ្នកអានច្រឡំ។ ប្រើមួយ ឬពីរ។

**៤. «សញ្ញាលំនាំដើមរបស់ QGIS គ្រប់គ្រាន់»**
លំនាំដើមមិនស្គាល់ទិន្នន័យ ឬអ្នកអានរបស់អ្នកទេ។ វាជាចំណុចចាប់ផ្ដើម មិនមែនលទ្ធផលទេ។

**៥. «សញ្ញាដែលច្បាស់លើអេក្រង់ ច្បាស់លើក្រដាស»**
អេក្រង់មានពន្លឺ និងភាពច្បាស់ខុសពីក្រដាស។ ត្រូវសាកល្បងបោះពុម្ពទំហំពិត។

## ៦.៧. សេចក្ដីសង្ខេបមេរៀន

អថេរមើលឃើញជាភាសានៃផែនទី។ ទំហំ និងតម្លៃពន្លឺបង្ហាញលំដាប់ និងបរិមាណ ឯពណ៌ រាង និងទិសដៅបង្ហាញភាពខុសគ្នា។ ការជ្រើសអថេរត្រូវផ្គូផ្គងនឹងកម្រិតរង្វាស់នៃទិន្នន័យ។

និមិត្តសញ្ញាចំណុច បន្ទាត់ និងផ្ទៃមានក្បួនផ្ទាល់ខ្លួន ហើយសញ្ញាសមាមាត្រត្រូវធ្វើមាត្រដ្ឋានតាមផ្ទៃ។ ឋានានុក្រមមើលឃើញធ្វើឲ្យធាតុសំខាន់លេចធ្លោ។

!!! abstract "គំនិតស្នូលនៃមេរៀន"
    មុនជ្រើសពណ៌ ឬទំហំ ត្រូវសួរថា «ទិន្នន័យនេះជាប្រភេទ លំដាប់ ឬបរិមាណ?» ចម្លើយកំណត់អថេរដែលត្រឹមត្រូវ។

## ៦.៨. ពាក្យគន្លឹះខ្មែរ–អង់គ្លេស

| ពាក្យខ្មែរ | ពាក្យអង់គ្លេស | អត្ថន័យខ្លី |
|---|---|---|
| អថេរមើលឃើញ | Visual variables | ទំហំ ពណ៌ រាង ... |
| តម្លៃពន្លឺ | Value / lightness | ស្រាល ↔ ដិត |
| ពណ៌ | Hue | ក្រហម ខៀវ បៃតង |
| វាយនភាព | Texture / pattern | លំនាំចំណុច ឬខ្សែ |
| ឋានានុក្រមមើលឃើញ | Visual hierarchy | លំដាប់ដែលភ្នែកមើល |
| សញ្ញាសមាមាត្រ | Proportional symbol | ទំហំតាមឫសការ៉េនៃតម្លៃ |
| និមិត្តសញ្ញាតាមប្រភេទ | Categorized symbology | ពណ៌ ឬរាងតាមថ្នាក់ |
| និមិត្តសញ្ញាតាមច្បាប់ | Rule-based symbology | តាមលក្ខខណ្ឌ |

## ៦.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយអថេរមើលឃើញប្រាំមួយ និងប្រាប់ថាមួយណាបង្ហាញលំដាប់។
2. ហេតុអ្វីមិនគួរប្រើទំហំសម្រាប់ទិន្នន័យប្រភេទ?
3. សរសេររូបមន្តកាំនៃសញ្ញាសមាមាត្រ ហើយពន្យល់ហេតុផល។
4. រាយវិធីបីដើម្បីបង្កើតឋានានុក្រមមើលឃើញ។
5. ពេលណាប្រើ Categorized និងពេលណាប្រើ Graduated ក្នុង QGIS?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. សម្រាប់ស្រទាប់ `Kh_Main_Roads_MPWT2014` ដែលមានវាលថ្នាក់ផ្លូវ និងស្ថានភាពផ្ទៃផ្លូវ ស្នើអថេរមើលឃើញសម្រាប់នីមួយៗ។
7. ផែនទីមួយប្រើពណ៌ ១២ ផ្សេងសម្រាប់ប្រភេទក្រប់ដី ១២។ ផ្ដល់មតិ និងជម្រើសផ្សេង។
8. រង្វង់តំណាងភូមិ ២ ៥០០ នាក់ មានកាំ ៥ មម។ ភូមិ ១០ ០០០ នាក់ គួរមានកាំប៉ុន្មាន?
9. ផែនទីទឹកជំនន់មួយ ដែលព្រំខេត្តដិតជាងតំបន់ជំនន់។ ពន្យល់បញ្ហាឋានានុក្រម និងវិធីកែ។
10. រចនាសញ្ញាចំណុចសម្រាប់ប្រភេទសេវាសាធារណៈបួន (សាលា មណ្ឌលសុខភាព ប៉ុស្តិ៍ប៉ូលិស ផ្សារ) ហើយពន្យល់ការជ្រើសរបស់អ្នក។

### គ. កិច្ចការខ្លី

ជ្រើសផែនទីមួយពីរបាយការណ៍ ឬកាសែត។ រាយអថេរមើលឃើញដែលវាប្រើ និងទិន្នន័យដែលអថេរនីមួយៗតំណាង។ កំណត់ថាការផ្គូផ្គងត្រឹមត្រូវឬទេ ហើយគូសរូបព្រាងផែនទីដដែល ជាមួយនិមិត្តសញ្ញាដែលអ្នកស្នើ។

### ខ. ការភ្ជាប់ទៅមេរៀនបន្ទាប់

យើងអាចជ្រើសអថេរត្រឹមត្រូវហើយ។ ប៉ុន្តែពេលទិន្នន័យជាបរិមាណ (ដង់ស៊ីតេប្រជាជន) យើងត្រូវបែងចែកវាជាថ្នាក់មុនដាក់ពណ៌។ ចូរបញ្ចប់ដោយបង្ហាញផែនទីដដែលពីរ ដែលចាត់ថ្នាក់ខុសគ្នា ហើយសួរ៖

> «ទិន្នន័យដូចគ្នា ប៉ុន្តែផែនទីមួយបង្ហាញវិសមភាពខ្លាំង មួយទៀតបង្ហាញស្មើៗគ្នា។ ហេតុអ្វី?»
