# លំហាត់ទី១៥៖ គម្រោងបញ្ចប់វគ្គ៖ ផែនទីប្រធានបទពេញលេញ

    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៥៖ ការធ្វើឲ្យទូទៅ សីលធម៌ផែនទី និងការចេញផ្សាយ](../lessons/lesson-15.md)

## ស្ថានភាព

លំហាត់ចុងក្រោយនេះជា **គម្រោងបញ្ចប់វគ្គ**។ អ្នកនឹងផលិតផែនទីប្រធានបទពេញលេញមួយ ស្ដីពីតំបន់ដែលអ្នកជ្រើស ព្រមទាំងរបាយការណ៍ខ្លីដែលពន្យល់ការសម្រេចចិត្តផែនទីវិទ្យារបស់អ្នក។

## គោលបំណង

- អនុវត្តខ្លឹមសារមេរៀនទាំង ១៥ ក្នុងផលិតផលតែមួយ។
- ធ្វើការសម្រេចចិត្តផែនទីវិទ្យា និងពន្យល់ហេតុផល។
- ផលិតផែនទីដែលអាចបោះពុម្ព និងចែករំលែកបាន។
- បង្ហាញភាពស្មោះត្រង់ និងដែនកំណត់។

## សំណួរគម្រោង

សំណួរល្អ គឺជាក់លាក់ អាចឆ្លើយបានដោយទិន្នន័យដែលមាន និងមានប្រយោជន៍៖

| សំណួរខ្សោយ | សំណួរល្អ |
|---|---|
| «ប្រជាជនកម្ពុជា» | «ដង់ស៊ីតេប្រជាជនតាមឃុំក្នុងខេត្តតាកែវ និងទំនាក់ទំនងជាមួយផ្លូវជាតិ» |
| «សាលារៀន» | «ការទទួលបានសាលាបឋមសិក្សាក្នុងស្រុកជនបទនៃខេត្តព្រះវិហារ» |
| «ទឹកជំនន់» | «ភូមិក្នុងវិសាលភាពទឹកជំនន់ឆ្នាំ ២០១១ តាមស្រុក ខេត្តកំពង់ធំ» |

## ជំហានទី១៖ សំណើ · ២០ នាទី

សរសេរ ១ ទំព័រ៖ សំណួរ · តំបន់ · ទិន្នន័យ និងប្រភព · ប្រភេទផែនទីដែលស្នើ ([មេរៀនទី៩](../lessons/lesson-09.md)–[១២](../lessons/lesson-12.md)) · ការធ្វើឲ្យស្តង់ដារ · និងដែនកំណត់ដែលរំពឹង។

## ជំហានទី២៖ ត្រៀមទិន្នន័យ · ៣០ នាទី

1. ទាញយក និងកាត់ទិន្នន័យតាមតំបន់សិក្សា។
2. ភ្ជាប់តារាង និងគណនាតម្លៃស្តង់ដារ (ដង់ស៊ីតេ ឬអត្រា)។
3. ពិនិត្យតម្លៃ NULL តម្លៃខ្លាំង និងឯកតាផ្ទៃ។
4. កត់ត្រាប្រភព ឆ្នាំ និង CRS ក្នុងឯកសារ `README.txt`។

## ជំហានទី៤៖ ផលិតផែនទី · ៦០ នាទី

1. រចនានិមិត្តសញ្ញា ពណ៌ និងថ្នាក់។
2. ដាក់ស្លាកតាមឋានានុក្រម និងស្រទាប់ស។
3. រៀបចំប្លង់ **A3 ផ្ដេក ឬបញ្ឈរ** ជាមួយធាតុពេញលេញ។
4. នាំចេញ PDF ៣០០ dpi និងកំណែ A4 សម្រាប់របាយការណ៍។

## ជំហានទី៥៖ របាយការណ៍ និងការត្រួតពិនិត្យ · ៣០ នាទី

របាយការណ៍ ២ ទៅ ៣ ទំព័រ៖

1. សំណួរ និងតំបន់សិក្សា
2. ទិន្នន័យ និងដំណើរការត្រៀម
3. តារាងការសម្រេចចិត្តផែនទីវិទ្យា (ជំហានទី៣)
4. ការបកស្រាយផែនទី ៣ ទៅ ៥ ប្រយោគ
5. **ដែនកំណត់ និងអ្វីដែលមិនអាចសន្និដ្ឋាន**
6. ប្រភព និងអាជ្ញាបណ្ណ

រួចអនុវត្តបញ្ជីត្រួតពិនិត្យសីលធម៌ ៧ ចំណុច ([មេរៀនទី១៥](../lessons/lesson-15.md))។
