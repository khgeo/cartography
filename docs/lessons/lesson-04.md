# មេរៀនទី៤៖ មាត្រដ្ឋាន និងការវាស់វែងលើផែនទី

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៤ ក្នុងចំណោម ១៥

មាត្រដ្ឋានប្រាប់ថាផែនទីតូចជាងពិភពពិតប៉ុន្មានដង។ វាកំណត់ថាអ្នកអាចវាស់ចម្ងាយបានដូចម្ដេច វត្ថុណាខ្លះអាចបង្ហាញបាន និងកម្រិតលម្អិតដែលអ្នកអានរំពឹង។

មេរៀននេះពន្យល់របៀបសរសេរមាត្រដ្ឋាន ការគណនាចម្ងាយ និងផ្ទៃ ភាពខុសគ្នារវាងមាត្រដ្ឋានធំ និងតូច និងបញ្ហាមាត្រដ្ឋានពេលផែនទីបង្ហាញលើអេក្រង់ ឬថតចម្លង។

## ៤.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. បែងចែកមាត្រដ្ឋានបីរបៀប៖ ប្រភាគតំណាង មាត្រដ្ឋានពាក្យ និងរបារមាត្រដ្ឋាន។
2. គណនាចម្ងាយ និងផ្ទៃលើដី ពីការវាស់លើផែនទី។
3. បែងចែកមាត្រដ្ឋានធំ និងមាត្រដ្ឋានតូច និងទំនាក់ទំនងជាមួយកម្រិតលម្អិត។
4. ពន្យល់ថាហេតុអ្វីរបារមាត្រដ្ឋានល្អជាងប្រភាគ សម្រាប់ផែនទីឌីជីថល និងការថតចម្លង។
5. ពន្យល់ការវាស់ចម្ងាយក្នុង QGIS៖ ប្លង់ (Cartesian) និងអេលីបសូអ៊ីត។

## ៤.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីដែលថតចម្លងពង្រីក

គ្រូម្នាក់ថតចម្លងផែនទីទីសណ្ឋាន **១ : ៥០ ០០០** ដោយពង្រីក **១៥០%** ដើម្បីឲ្យសិស្សមើលច្បាស់។ សិស្សវាស់ចម្ងាយពីភូមិទៅសាលាបាន ៦ សង់ទីម៉ែត្រ ហើយគណនាតាមលេខ «១ : ៥០ ០០០» ដែលបោះពុម្ពលើផែនទី៖ ៦ × ៥០ ០០០ = ៣ គីឡូម៉ែត្រ។ ចម្ងាយពិតគឺ ២ គីឡូម៉ែត្រ។

ក្រោយពង្រីក ផែនទីមិនមែនជា ១ : ៥០ ០០០ ទៀតទេ។ ប៉ុន្តែរបារមាត្រដ្ឋាននៅគែមផែនទី នៅតែត្រឹមត្រូវ។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- មាត្រដ្ឋានសរសេរបានប៉ុន្មានរបៀប ហើយរបៀបណាប្រើបានពេលណា?
- «មាត្រដ្ឋានធំ» មានន័យថាផ្ទៃធំ ឬលម្អិតច្រើន?
- ពេលផែនទីនៅលើអេក្រង់ ឬទូរស័ព្ទ តើមាត្រដ្ឋាន «១ : ៥០ ០០០» នៅមានន័យឬទេ?

## ៤.៣. ទ្រឹស្ដីស្នូល

### ៤.៣.១. មាត្រដ្ឋាន និងរបៀបសរសេរ

**មាត្រដ្ឋានផែនទី (Map scale)** គឺជាសមាមាត្ររវាងចម្ងាយលើផែនទី និងចម្ងាយពិតលើដី។

<figure markdown>
--8<-- "assets/svg/c04-scale-types.svg"
<figcaption>រូបទី៤.១៖ មាត្រដ្ឋានបីរបៀបសម្រាប់ផែនទី ១ : ៥០ ០០០ (៣៨ ភីកសែល ≈ ១ សម មិនមែនទំហំពិតលើអេក្រង់)។ របារមាត្រដ្ឋានពង្រីក ឬបង្រួមជាមួយផែនទី ដូច្នេះប្រើបានលើអេក្រង់ និងពេលថតចម្លង។</figcaption>
</figure>

| របៀប | ឧទាហរណ៍ | គុណសម្បត្តិ | គុណវិបត្តិ |
|---|---|---|---|
| **ប្រភាគតំណាង (Representative Fraction, RF)** | ១ : ៥០ ០០០ | គ្មានឯកតា ប្រើបានគ្រប់ប្រព័ន្ធ | ខុសពេលពង្រីក បង្រួម ឬលើអេក្រង់ |
| **មាត្រដ្ឋានពាក្យ** | «១ សម ស្មើ ៥០០ ម» | ងាយយល់សម្រាប់មនុស្សទូទៅ | ខុសពេលពង្រីក បង្រួម |
| **របារមាត្រដ្ឋាន** | ████░░░░ ២ គម | ពង្រីកជាមួយផែនទី នៅតែត្រឹមត្រូវ | ត្រូវវាស់ដោយបន្ទាត់ |

**១ : ៥០ ០០០** មានន័យថា ១ ឯកតាលើផែនទី ស្មើ ៥០ ០០០ ឯកតាដូចគ្នាលើដី៖ ១ សម = ៥០ ០០០ សម = ៥០០ ម។

### ៤.៣.២. គណនាចម្ងាយ និងផ្ទៃ

**ចម្ងាយ**៖

- ចម្ងាយលើដី = ចម្ងាយលើផែនទី × ភាគបែងមាត្រដ្ឋាន
- ចម្ងាយលើផែនទី = ចម្ងាយលើដី ÷ ភាគបែងមាត្រដ្ឋាន
- មាត្រដ្ឋាន = ចម្ងាយលើផែនទី ÷ ចម្ងាយលើដី (ឯកតាដូចគ្នា)

ឧទាហរណ៍៖ ៤ សម លើផែនទី ១ : ៥០ ០០០ = ៤ × ៥០ ០០០ = ២០០ ០០០ សម = **២ គម**។

**ផ្ទៃ**៖ មាត្រដ្ឋានផ្ទៃ = **ការ៉េ** នៃមាត្រដ្ឋានលីនេអ៊ែរ។ ការ៉េ ២ × ២ សម លើផែនទី ១ : ៥០ ០០០ = (២ × ៥០០ ម)² = ១ ០០០ ០០០ ម² = **១ គម²** = ១០០ ហ.ត។

!!! warning "កុំភ្លេចការ៉េ"
    ពេលពង្រីកផែនទី ២ ដង ចម្ងាយពង្រីក ២ ដង ប៉ុន្តែផ្ទៃពង្រីក **៤ ដង**។

!!! example "ពិសោធន៍៖ មាត្រដ្ឋាន និងការពង្រីក"
    ជ្រើសមាត្រដ្ឋាន និងចម្ងាយវាស់ ដើម្បីគណនាចម្ងាយលើដី។ បន្ទាប់មករំកិល «ថតចម្លងពង្រីក» ទៅ ១៥០% ហើយមើលថាអ្វីត្រឹមត្រូវ និងអ្វីខុស។

ពាក្យ «ធំ» និង «តូច» សំដៅលើ **តម្លៃប្រភាគ** មិនមែនទំហំផ្ទៃទេ៖

### ៤.៣.៤. មាត្រដ្ឋានលើអេក្រង់ និងក្នុង QGIS

លើអេក្រង់ មាត្រដ្ឋានពិតប្រាកដអាស្រ័យលើទំហំ និងភាពច្បាស់នៃអេក្រង់។ ផែនទីដដែលមើលលើកុំព្យូទ័រ ២៧ អ៊ីញ និងទូរស័ព្ទ មានមាត្រដ្ឋានពិតខុសគ្នាច្រើន។ ដូច្នេះ៖

- **ផែនទីឌីជីថល** ត្រូវប្រើ **របារមាត្រដ្ឋាន**។
- **ផែនទីបោះពុម្ព** អាចប្រើ RF ពេលបោះពុម្ពទំហំពិត (ឧ. A4 ១០០%) ហើយគួរដាក់របារមាត្រដ្ឋានផង។
- ក្នុង **Print Layout** របស់ QGIS អ្នកកំណត់មាត្រដ្ឋានពិតប្រាកដនៃប្រអប់ផែនទី ដែលត្រឹមត្រូវពេលបោះពុម្ពទំហំពិត។

**ការវាស់ក្នុង QGIS** (ឧបករណ៍ Measure Line)៖

| ជម្រើស | គណនាលើ | ពេលប្រើ |
|---|---|---|
| **Cartesian** | ប្លង់នៃ CRS | ពេល CRS ជាម៉ែត្រ និងតំបន់តូច (UTM 48N នៅកម្ពុជា) |
| **Ellipsoidal** | អេលីបសូអ៊ីត (Geodesic) | ចម្ងាយឆ្ងាយ ឬពេល CRS ជាដឺក្រេ ឬ Web Mercator |

នៅកម្ពុជា ក្នុង UTM 48N ភាពខុសគ្នារវាងវិធីទាំងពីរតិចជាង ០,១%។ ក្នុង Web Mercator ចម្ងាយ Cartesian អាចធំជាងពិតរហូតដល់ ៣%។

សិស្សវាស់ចម្ងាយបន្ទាត់ត្រង់ពីចំណុចភ្នំពេញ ទៅចំណុចទីរួមខេត្តកំពង់ឆ្នាំង (ស្រទាប់ `Kh_Province_Center`) លើផែនទីបោះពុម្ព ១ : ១ ០០០ ០០០។

### ជំហានទី១៖ វាស់លើផែនទី

បន្ទាត់វាស់បាន **៨,០ សម**។

### ជំហានទី២៖ គណនា

៨,០ × ១ ០០០ ០០០ = ៨ ០០០ ០០០ សម = **៨០ គម**។

### ជំហានទី៣៖ ផ្ទៀងផ្ទាត់ក្នុង QGIS

ក្នុង UTM 48N ចម្ងាយ Cartesian = **៧៩,៧ គម** · Ellipsoidal = **៧៩,៧ គម**។ ភាពខុសគ្នា ០,៣ គម ជាកំហុសវាស់ដោយបន្ទាត់ (១ មម លើផែនទី = ១ គម លើដី)។

### ជំហានទី៤៖ បើផែនទីត្រូវបានបង្រួម

បើផែនទីនេះត្រូវបានបោះពុម្ពបង្រួមមក ៧០% ហើយសិស្សប្រើលេខ «១ : ១ ០០០ ០០០» ដដែល ចម្ងាយវាស់នឹង ៥,៦ សម → ៥៦ គម ដែលខុស ២៤ គម។ ប្រើរបារមាត្រដ្ឋានវិញ ចម្លើយនៅតែ ~៨០ គម។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ចម្ងាយបន្ទាត់ត្រង់ពីចំណុចភ្នំពេញទៅទីរួមខេត្តកំពង់ឆ្នាំងប្រហែល ៨០ គីឡូម៉ែត្រ។ ការវាស់លើផែនទី ១ : ១ ០០០ ០០០ មានកំហុសប្រហែល ១ គម ក្នុងមួយមីលីម៉ែត្រ ហើយលេខ RF នឹងខុស បើផែនទីត្រូវបានពង្រីក ឬបង្រួម។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    យើងមិនអាចនិយាយថាអ្នកធ្វើដំណើរពីភ្នំពេញទៅកំពង់ឆ្នាំងចម្ងាយ ៨០ គម ទេ។ ចម្ងាយតាមផ្លូវជាតិវែងជាងបន្ទាត់ត្រង់ ហើយចំណុចក្នុងស្រទាប់តំណាងទីរួមខេត្ត ដែលអាចមិនមែនជាកន្លែងចាប់ផ្ដើម ឬគោលដៅពិត។

## ៤.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «មាត្រដ្ឋានធំ = ផ្ទៃធំ»**
មាត្រដ្ឋានធំ = ប្រភាគធំ = ផ្ទៃតូច = លម្អិតច្រើន។

**២. «RF នៅតែត្រឹមត្រូវលើអេក្រង់»**
ទំហំអេក្រង់ និងការពង្រីកប្ដូរមាត្រដ្ឋានពិត។ ប្រើរបារមាត្រដ្ឋានសម្រាប់ផែនទីឌីជីថល។

**៣. «ពង្រីកផែនទី ២ ដង ផ្ទៃក៏ ២ ដង»**
ផ្ទៃប្ដូរតាមការ៉េនៃមាត្រដ្ឋាន៖ ២ × ២ = ៤ ដង។

**៤. «ផែនទីមាត្រដ្ឋានណាក៏អាចពង្រីកឲ្យលម្អិតបាន»**
ការពង្រីកលើអេក្រង់ មិនបន្ថែមព័ត៌មានទេ។ ទិន្នន័យ ១ : ១ ០០០ ០០០ ពង្រីកមក ១ : ១០ ០០០ នៅតែមានលម្អិតនិងកំហុសទីតាំងនៃ ១ : ១ ០០០ ០០០។

**៥. «ផែនទីទាំងមូលមានមាត្រដ្ឋានតែមួយ»**
ដោយសារចំណោល មាត្រដ្ឋានពិតប្រែប្រួលពីកន្លែងមួយទៅកន្លែងមួយ។ នៅកម្ពុជាក្នុង UTM 48N ប្រែប្រួលតិចជាង ០,១% ប៉ុន្តែលើផែនទីពិភពលោក អាចប្រែប្រួលច្រើនដង។

## ៤.៧. សេចក្ដីសង្ខេបមេរៀន

មាត្រដ្ឋានធំបង្ហាញផ្ទៃតូច ដែលមានលម្អិតច្រើន។ ផែនទីឌីជីថល និងផែនទីដែលអាចថតចម្លង ត្រូវមានរបារមាត្រដ្ឋាន។ ក្នុង QGIS ការវាស់ Cartesian ក្នុង UTM 48N និងការវាស់ Ellipsoidal ផ្ដល់លទ្ធផលស្ទើរដូចគ្នានៅកម្ពុជា។

### ខ. សំណួរអនុវត្តគោលគំនិត
