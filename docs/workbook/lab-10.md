# លំហាត់ទី១០៖ សញ្ញាសមាមាត្រ និងផែនទីចំណុចដង់ស៊ីតេ

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១០៖ និមិត្តសញ្ញាសមាមាត្រ និងផែនទីចំណុចដង់ស៊ីតេ](../lessons/lesson-10.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

របាយការណ៍ដដែលត្រូវការផែនទីបង្ហាញ **ចំនួន**៖ ចំនួនប្រជាជនតាមខេត្ត និងចំនួនសិស្សតាមស្រុក។ អ្នកនឹងធ្វើផែនទីសញ្ញាសមាមាត្រ និងផែនទីចំណុចដង់ស៊ីតេ ហើយប្រៀបធៀបជាមួយ Choropleth។

## គោលបំណង

- បង្កើតសញ្ញាសមាមាត្រដោយ Data-defined override និងឫសការ៉េ។
- បង្កើតសញ្ញាចាត់ថ្នាក់ និងប្រៀបធៀបជាមួយសញ្ញាបន្ត។
- រៀបចំសញ្ញាសម្គាល់ផែនទីទំហំ (Data-defined size legend)។
- បង្កើតផែនទីចំណុចដង់ស៊ីតេ និងជ្រើសតម្លៃចំណុច។

## ពិសោធន៍មុនចាប់ផ្ដើម · ១០ នាទី

## សកម្មភាពទី១៖ សញ្ញាសមាមាត្រ · ២៥ នាទី

1. **Vector → Geometry Tools → Point on Surface** លើ `Kh_Province_Boundary` → `prov_points` (ចំណុចនេះនៅក្នុងខេត្តជានិច្ច ខុសពីផ្ចិតធរណីមាត្រ)។
2. Symbology → Single Symbol → Size → Data-defined override → Expression៖

    ```text
    0.0068 * sqrt("POP2017")
    ```

    ឯកតា **Millimeters**។ ភ្នំពេញ (១ ៤០៣ ២៩៣) → ៨,០ មម · កែប (៤១ ១៧៧) → ១,៤ មម។

3. កំណត់ភាពថ្លា ៦៥% ព្រំពណ៌ស ០,២ មម ហើយដាក់ស្រទាប់ព្រំខេត្តពណ៌ស្រាលនៅក្រោម។
4. សាកល្បងកន្សោមខុស `0.0000057 * "POP2017"` (មាត្រដ្ឋានកាំ) ហើយប្រៀបធៀបលទ្ធផល។

## សកម្មភាពទី២៖ សញ្ញាសម្គាល់ផែនទីទំហំ · ២០ នាទី

1. Layer Properties → **Legend** → Data-defined size legend → **Separated legend items**។
2. កំណត់ថ្នាក់តម្លៃមូល៖ ២០០ ០០០ · ៧០០ ០០០ · ១ ៤០០ ០០០។
3. ពិនិត្យក្នុង Print Layout ថាសញ្ញាសម្គាល់ផែនទីបង្ហាញរង្វង់បីត្រឹមត្រូវ។

**សំណួរ៖** ហេតុអ្វីតម្លៃក្នុងសញ្ញាសម្គាល់ផែនទីគួរជាលេខមូល ហើយរង្វង់ធំបំផុតគួរស្មើតម្លៃអតិបរមា?

## សកម្មភាពទី៣៖ សញ្ញាចាត់ថ្នាក់ · ១៥ នាទី

1. ចម្លងស្រទាប់ `prov_points` → Symbology → **Graduated** · Value `POP2017` · Method **Size** · ៥ ថ្នាក់ · Natural Breaks · Size from `2` to `10` មម។
2. ប្រៀបធៀបជាមួយសញ្ញាបន្ត៖ មួយណាងាយអានតម្លៃជាង? មួយណារក្សាព័ត៌មានច្រើនជាង?

## សកម្មភាពទី៤៖ ផែនទីចំណុចដង់ស៊ីតេ · ២៥ នាទី

1. QGIS គ្មានប្រភេទនិមិត្តសញ្ញា «ចំណុចដង់ស៊ីតេ» ដោយផ្ទាល់ទេ។ យើងបង្កើតចំណុចជាស្រទាប់ថ្មីវិញ ដោយ **Processing → Vector creation → Random points in polygons**៖
    - Input `Kh_Province_Boundary`
    - Point count or density៖ **Expression**៖ `round("POP2017" / 10000)`
    - Minimum distance `0` → `dots_10000`
2. និមិត្តសញ្ញាចំណុច៖ រង្វង់ពណ៌ក្រហម ០,៦ មម ភាពថ្លា ៨០%។
3. ធ្វើម្ដងទៀតជាមួយ `round("POP2017" / 50000)` → `dots_50000` ហើយប្រៀបធៀប។
4. បន្ថែមចំណាំលើផែនទី៖ «១ ចំណុច = ១០ ០០០ នាក់ · ចំណុចដាក់ចៃដន្យក្នុងខេត្ត»។

!!! tip "ចំណុចត្រឹមត្រូវជាង"
    ដើម្បីកុំឲ្យចំណុចធ្លាក់លើបឹង ឬភ្នំ អាចកាត់ខេត្តចេញពីផ្ទៃទឹកជាមុន (Difference ជាមួយ `Kh_Lake_n_Mekong`) រួចដាក់ចំណុចក្នុងផ្ទៃដែលនៅសល់។ វិធីនេះហៅថា **dasymetric**។

## សកម្មភាពទី៥៖ ប្រៀបធៀប និងជ្រើស · ១៥ នាទី

ដាក់ផែនទីបីក្នុងប្លង់តែមួយ (Choropleth ដង់ស៊ីតេ · សញ្ញាសមាមាត្រ · ចំណុចដង់ស៊ីតេ) ហើយសរសេរ ៣ ទៅ ៥ ប្រយោគ៖ ផែនទីណាឆ្លើយសំណួរណា?

## លទ្ធផលត្រូវប្រគល់

- ផែនទីសញ្ញាសមាមាត្រ ជាមួយសញ្ញាសម្គាល់ផែនទីទំហំ។
- ផែនទីចំណុចដង់ស៊ីតេពីរ (១០ ០០០ និង ៥០ ០០០ នាក់ក្នុងមួយចំណុច)។
- ប្លង់ប្រៀបធៀបផែនទីបី និងការពន្យល់។
