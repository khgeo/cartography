# លំហាត់ទី២៖ កូអរដោនេ ដាតុម និង CRS ក្នុង QGIS

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី២៖ រាងផែនដី ដាតុម និងប្រព័ន្ធកូអរដោនេ](../lessons/lesson-02.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

ការិយាល័យមួយផ្ញើកូអរដោនេទីរួមខេត្តមកជាពីរទម្រង់៖ ដឺក្រេ នាទី វិនាទីពីផែនទីចាស់ និងម៉ែត្រក្នុង Indian 1960។ អ្នកត្រូវនាំវាចូល QGIS ឲ្យត្រូវនឹងទិន្នន័យវគ្គសិក្សា (WGS 84 / UTM zone 48N) ហើយវាស់ថាដាតុមខុស ធ្វើឲ្យរំកិលប៉ុណ្ណា។

## គោលបំណង

- អាន CRS របស់ស្រទាប់ និងគម្រោង ហើយស្គាល់លេខ EPSG។
- អាន និងបម្លែងកូអរដោនេរវាង UTM ដឺក្រេទសភាគ និង DMS។
- បែងចែក Set Layer CRS និង Reproject Layer ដោយការសាកល្បង។
- វាស់ផលប៉ះពាល់នៃដាតុមខុស និងជ្រើសការបំប្លែងដាតុម។

## សកម្មភាពទី១៖ ពិនិត្យ CRS · ១៥ នាទី

1. បង្កើតគម្រោងថ្មី `lab02.qgz` ហើយបន្ថែមស្រទាប់ទាំងបី។
2. **Layer Properties → Information** នៃស្រទាប់នីមួយៗ៖ កត់ត្រា CRS ឈ្មោះ លេខ EPSG និងឯកតា។
3. ចុចលើប៊ូតុង CRS នៅជ្រុងខាងក្រោមស្ដាំ។ កត់ត្រា CRS គម្រោង។
4. រំកិលកណ្ដុរលើទីក្រុងភ្នំពេញ ហើយមើលកូអរដោនេនៅរបារខាងក្រោម (Coordinate)។

**សំណួរ៖** ឯកតានៃកូអរដោនេនៅរបារខាងក្រោមជាអ្វី? តើវាប្ដូរ ពេលអ្នកប្ដូរ CRS គម្រោងទៅ EPSG:4326?

## សកម្មភាពទី២៖ អាន និងបម្លែងកូអរដោនេ · ២០ នាទី

1. ប្រើ **Identify Features** ចុចលើចំណុចភ្នំពេញក្នុង `Kh_Province_Center`។ ក្នុងផ្ទាំងលទ្ធផល មើល **(Derived)**៖ X Y ក្នុង CRS ស្រទាប់។
2. Field Calculator លើ `Kh_Province_Center` (បើក Toggle editing ក៏បាន ឬបង្កើតវាលបណ្ដោះអាសន្ន)៖

    | វាល | កន្សោម |
    |---|---|
    | `E` | `$x` |
    | `N` | `$y` |
    | `lon` | `x(transform($geometry, 'EPSG:32648', 'EPSG:4326'))` |
    | `lat` | `y(transform($geometry, 'EPSG:32648', 'EPSG:4326'))` |
    | `lat_dms` | `to_dms(y(transform($geometry,'EPSG:32648','EPSG:4326')),'y',1)` |

3. ពិនិត្យលទ្ធផលសម្រាប់ភ្នំពេញ ហើយបម្លែង `lat` ទៅ DMS ដោយដៃ។ ប្រៀបធៀបជាមួយ `lat_dms`។

## សកម្មភាពទី៣៖ Set CRS ឬ Reproject? · ២០ នាទី

1. ចម្លងស្រទាប់ `Kh_Province_Center` → Duplicate Layer → ប្ដូរឈ្មោះ `wrong_label`។
2. ចុចស្ដាំ `wrong_label` → **Layer CRS → Set Layer CRS** → ជ្រើស **EPSG:3148 (Indian 1960 / UTM zone 48N)**។
3. សង្កេតលើផែនទី។ ចំណុចរំកិលទៅណា ធៀបនឹងស្រទាប់ដើម?
4. ម្ដងទៀតពីស្រទាប់ដើម៖ **Vector → Data Management Tools → Reproject Layer** → Target CRS **EPSG:3148** → `reprojected`។ ពេល QGIS បើកប្រអប់ **Select Transformation** ជ្រើសការបំប្លែងដែល Area of use មាន Cambodia។
5. សង្កេត៖ ស្រទាប់ `reprojected` ត្រួតនឹងស្រទាប់ដើមលើផែនទីឬទេ? ប្រៀបធៀបលេខ `$x` `$y` នៃភ្នំពេញក្នុងស្រទាប់ទាំងពីរ។

!!! danger "ចំណុចសំខាន់"
    **Set Layer CRS** មិនប្ដូរលេខ ប៉ុន្តែប្ដូរទីតាំងលើផែនទី (ព្រោះ QGIS យល់លេខដដែលក្នុងប្រព័ន្ធថ្មី)។ **Reproject** ប្ដូរលេខ ប៉ុន្តែទីតាំងលើផែនទីនៅដដែល។

## សកម្មភាពទី៤៖ វាស់ការរំកិលនៃដាតុម · ២០ នាទី

1. ប្រើ **Measure Line** វាស់ចម្ងាយពីចំណុចភ្នំពេញក្នុងស្រទាប់ដើម ទៅចំណុចភ្នំពេញក្នុង `wrong_label`។
2. ធ្វើម្ដងទៀតសម្រាប់ទីរួមខេត្តពីរផ្សេងទៀត (ឧ. រតនគិរី និងកោះកុង)។ ការរំកិលស្មើគ្នាឬទេ?
3. បំពេញតារាង៖

    | ទីរួមខេត្ត | E ដើម | N ដើម | ចម្ងាយរំកិល (ម) | ទិស |
    |---|---:|---:|---:|---|
    | ភ្នំពេញ | | | | |
    | | | | | |
    | | | | | |

**សំណួរ៖** បើអ្នកទទួលទិន្នន័យរំកិលស្ទើរស្មើៗគ្នា ៥០០ ម ទៅទិសដូចគ្នា តើអ្នកនឹងសង្ស័យអ្វីមុនគេ?

## សកម្មភាពទី៥៖ នាំចូលកូអរដោនេ DMS · ១៥ នាទី

1. បង្កើតឯកសារ `points.csv` ក្នុង Notepad៖

    ```text
    name,lat_dms,lon_dms
    Independence Monument,11°33'23"N,104°55'42"E
    ```

2. **Add Delimited Text Layer** ជាមួយ **DMS coordinates** ធីក · X `lon_dms` · Y `lat_dms` · CRS **EPSG:4326**។
3. ពិនិត្យថាចំណុចធ្លាក់ត្រូវវិមានឯករាជ្យ។ វាស់ចម្ងាយពីចំណុចនេះ ទៅចំណុចភ្នំពេញក្នុង `Kh_Province_Center`។
