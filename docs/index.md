# សៀវភៅទី១៖ ផែនទីវិទ្យា

### សម្រាប់វគ្គសិក្សា ១ ឆមាស · ៤៥ ម៉ោង · ១៥ មេរៀន · ១៥ លំហាត់ QGIS · ជាភាសាខ្មែរ

---

សៀវភៅនេះជាឯកសារបង្រៀនសម្រាប់មុខវិជ្ជា **ផែនទីវិទ្យា (Cartography)** កម្រិតបរិញ្ញាបត្រ ឆ្នាំទី២ ឆមាសទី១ ដេប៉ាតឺម៉ង់ភូមិវិទ្យា និងរៀបចំដែនដី។ វាមាន **១៥ មេរៀនទ្រឹស្ដី** (៣ ម៉ោងក្នុងមួយមេរៀន) និង **សៀវភៅអនុវត្ត ១៥ លំហាត់** លើ **QGIS** ដែលប្រើទិន្នន័យពិតរបស់កម្ពុជា។ មេរៀន និងលំហាត់មានរូបភាព ពិសោធន៍អន្តរកម្ម និងប្រអប់ពិនិត្យខ្លួនឯង។

ខ្លឹមសារទាំងអស់ត្រូវបានសរសេរក្នុងបរិបទ **កម្ពុជា**។

## ស៊េរីសៀវភៅទាំង ៤

សៀវភៅនេះជាផ្នែកមួយនៃស៊េរីសម្រាប់ឆ្នាំទី២ និងទី៣។ មើលស៊េរីទាំងមូលនៅ [khgeo.github.io](https://khgeo.github.io/)។

| សៀវភៅ | ចំណងជើង | ឆ្នាំ/ឆមាស |
|---|---|---|
| **ទី១** | **ផែនទីវិទ្យា** ← សៀវភៅនេះ | ឆ្នាំទី២ ឆមាសទី១ |
| ទី២ | [មូលដ្ឋានគ្រឹះនៃ GIS](https://khgeo.github.io/gis-fundamentals/) | ឆ្នាំទី២ ឆមាសទី២ |
| ទី៣ | មូលដ្ឋានគ្រឹះនៃការយកព័ត៌មានពីចម្ងាយ | ឆ្នាំទី៣ ឆមាសទី១ |
| ទី៤ | GIS និងការយកព័ត៌មានពីចម្ងាយអនុវត្តន៍ | ឆ្នាំទី៣ ឆមាសទី២ |

!!! abstract "អ្វីដែលសៀវភៅនេះបង្រៀន និងមិនបង្រៀន"
    សៀវភៅនេះបង្រៀន **រាងផែនដី ប្រព័ន្ធកូអរដោនេ ចំណោល មាត្រដ្ឋាន ការអានផែនទីទីសណ្ឋាន និមិត្តសញ្ញា ការចាត់ថ្នាក់ ពណ៌ ផែនទីប្រធានបទ អក្សរ និងប្លង់ផែនទី**។ សៀវភៅទី២ ប្រើខ្លឹមសារទាំងនេះជាឧបករណ៍ ដោយមិនបង្រៀនឡើងវិញ។

    **ការរក្សាទុក ការភ្ជាប់តារាង និងការវិភាគលំហ** (បាហ្វ័រ ការត្រួតស្រទាប់ ពីជគណិតផែនទី) ជាខ្លឹមសារសៀវភៅទី២។ **រូបភាពផ្កាយរណប** ជាខ្លឹមសារសៀវភៅទី៣។
