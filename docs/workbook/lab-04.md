# លំហាត់ទី៤៖ វាស់ចម្ងាយ និងរៀបចំផែនទីតាមមាត្រដ្ឋាន

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៤៖ មាត្រដ្ឋាន និងការវាស់វែងលើផែនទី](../lessons/lesson-04.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ៩០ នាទី

## ស្ថានភាព

ក្រសួងអប់រំត្រូវការផែនទីបោះពុម្ពទំហំ A4 ដែលសិស្សអាចវាស់ចម្ងាយពីភ្នំពេញទៅទីរួមខេត្តដោយបន្ទាត់។ ផែនទីត្រូវមានមាត្រដ្ឋានពិតប្រាកដ និងរបារមាត្រដ្ឋានត្រឹមត្រូវ។

## គោលបំណង

- វាស់ចម្ងាយក្នុង QGIS ដោយ Cartesian និង Ellipsoidal ហើយប្រៀបធៀប។
- គណនាចម្ងាយរវាងចំណុចច្រើនដោយ Distance Matrix។
- កំណត់មាត្រដ្ឋានពិតប្រាកដក្នុង Print Layout ហើយផ្ទៀងផ្ទាត់ក្រោយបោះពុម្ព។
- រចនារបារមាត្រដ្ឋានដែលអានងាយ។

## សកម្មភាពទី១៖ វាស់ចម្ងាយ · ២០ នាទី

1. កំណត់ CRS គម្រោង EPSG:32648 ហើយបន្ថែមស្រទាប់ទាំងបី។
2. **Measure Line** (Ctrl+Shift+M)៖ វាស់ពីចំណុចភ្នំពេញ ទៅទីរួមខេត្តកំពង់ឆ្នាំង (បើក Snapping ទៅ `Kh_Province_Center`)។
3. ក្នុងប្រអប់ Measure ប្ដូររវាង **Cartesian** និង **Ellipsoidal** ហើយកត់ត្រាទាំងពីរ។
4. ប្ដូរ CRS គម្រោងទៅ EPSG:3857 ហើយវាស់ Cartesian ម្ដងទៀត។ ប្រៀបធៀប។

| CRS គម្រោង | Cartesian (គម) | Ellipsoidal (គម) |
|---|---:|---:|
| EPSG:32648 | | |
| EPSG:3857 | | |

## សកម្មភាពទី២៖ តារាងចម្ងាយ · ២០ នាទី

1. **Vector → Analysis Tools → Distance Matrix**៖ Input `Kh_Province_Center` · ID `Name_EN` · Target `Kh_Province_Center` · ID `Name_EN` · **Standard (N × T) distance matrix** → `dist_matrix.csv`
2. បើកតារាងលទ្ធផល។ ចម្ងាយជាម៉ែត្រ ក្នុង CRS ស្រទាប់ (UTM 48N)។
3. រកទីរួមខេត្ត ៣ ដែលឆ្ងាយពីភ្នំពេញជាងគេ និង ៣ ដែលជិតជាងគេ (ក្រៅពីភ្នំពេញខ្លួនឯង)។

## សកម្មភាពទី៣៖ ផែនទីមាត្រដ្ឋានពិតប្រាកដ · ៣០ នាទី

1. **New Print Layout** ទំហំ **A4 Portrait**។
2. Add Map៖ ក្នុង Item Properties កំណត់ **Scale** ជា `2500000` ហើយកែទំហំប្រអប់ឲ្យកម្ពុជាសមនឹងក្រដាស។
3. Add Scale Bar៖

    | ការកំណត់ | តម្លៃ |
    |---|---|
    | Style | Single Box |
    | Units | Kilometers |
    | Fixed width | `25` |
    | Segments | ឆ្វេង `0` · ស្ដាំ `4` |

4. Add Label ជាមួយ Expression៖ `'មាត្រដ្ឋាន ១ : ' || format_number(item_variables('Map 1')['map_scale'], 0)` (ប្ដូរ `Map 1` តាមឈ្មោះប្រអប់ផែនទី)។
5. បន្ថែមចំណងជើង សញ្ញាសម្គាល់ផែនទី ប្រភព CRS។ Export PDF ៣០០ dpi។
6. **បោះពុម្ពទំហំពិត (១០០% · មិនមែន Fit to page)**។ វាស់ចម្ងាយភ្នំពេញ–កំពង់ឆ្នាំងដោយបន្ទាត់ ហើយគណនាតាម RF និងតាមរបារមាត្រដ្ឋាន។

!!! warning "Fit to page"
    ពេលបោះពុម្ពជាមួយ «Fit to page» ឬ «Shrink» ផែនទីត្រូវបានបង្រួម ហើយ RF លើផែនទីខុស។ របារមាត្រដ្ឋាននៅតែត្រឹមត្រូវ។

## សកម្មភាពទី៤៖ ឆ្លុះបញ្ចាំង · ១០ នាទី

សរសេរ ៣ ទៅ ៥ ប្រយោគ៖ ចម្ងាយពី QGIS ពីផែនទីបោះពុម្ពតាម RF និងតាមរបារមាត្រដ្ឋាន ខុសគ្នាប៉ុណ្ណា ហើយហេតុអ្វី?
