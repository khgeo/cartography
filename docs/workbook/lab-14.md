# លំហាត់ទី១៤៖ ប្លង់ផែនទី A4 និង A3

    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៤៖ ប្លង់ផែនទី និងឋានានុក្រមមើលឃើញ](../lessons/lesson-14.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

ផែនទីដដែលត្រូវការពីរកំណែ៖ **A4 បញ្ឈរ** សម្រាប់របាយការណ៍ និង **A3 ផ្ដេក** សម្រាប់បទបង្ហាញលើជញ្ជាំង។ ការសម្រេចចិត្តរចនាខុសគ្នា។

## គោលបំណង

- រៀបចំប្លង់ដោយប្រើក្រឡាតម្រឹម និងឧបករណ៍ Align។
- កំណត់មាត្រដ្ឋានពិតប្រាកដ និងធាតុអមពេញលេញ។
- ប្រើ Atlas ដើម្បីបង្កើតផែនទីច្រើនស្វ័យប្រវត្តិ។
- នាំចេញ PDF ៣០០ dpi និង PNG សម្រាប់អេក្រង់។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

## សកម្មភាពទី១៖ ប្លង់ A4 បញ្ឈរ · ៣០ នាទី

1. New Print Layout `report_a4` · A4 Portrait។
2. **View → Show Grid** និង **Snap to Grid** (ចន្លោះ ៥ មម)។
3. រៀបចំធាតុ៖

    | ធាតុ | ទីតាំង និងទំហំ (មម) |
    |---|---|
    | ចំណងជើង | x ២០ · y ១៥ · ទំហំអក្សរ ១៦ pt |
    | ផែនទី | x ២០ · y ៣០ · ១៧០ × ១៦០ |
    | សញ្ញាសម្គាល់ផែនទី | x ២០ · y ១៩៥ |
    | មាត្រដ្ឋាន និងទិស | x ១០០ · y ១៩៥ |
    | ផែនទីទីតាំង | x ១៤៥ · y ១៩៥ · ៤៥ × ៤៥ |
    | ប្រភព · CRS · ថ្ងៃ | x ២០ · y ២៦០ · ៧ pt |

4. ប្រើ **Align Left / Align Top** (Layout → Align Items) ដើម្បីតម្រឹមគែមឆ្វេងនៃចំណងជើង ផែនទី សញ្ញាសម្គាល់ផែនទី និងប្រភព។
5. កំណត់ Scale ជាលេខមូល (ឧ. `1:2 500 000`)។

## សកម្មភាពទី២៖ ប្លង់ A3 ផ្ដេក · ២៥ នាទី

1. Duplicate Layout → `presentation_a3` → Page Properties → A3 Landscape។
2. កែ៖ អក្សរចំណងជើង ២៤ pt · ស្លាក ១០ pt · សញ្ញាសម្គាល់ផែនទីធំជាង · ផែនទីកាន់កាប់ផ្ទៃធំជាង។
3. ពិចារណាលុបធាតុមួយចំនួន (ឧ. អត្ថបទវែង) ព្រោះអ្នកអានឈរឆ្ងាយ។

**សំណួរ៖** អ្វីខ្លះដែលអ្នកបានកែ ក្រៅពីទំហំក្រដាស? ហេតុអ្វី?

## សកម្មភាពទី៣៖ Atlas · ២០ នាទី

1. ក្នុង `report_a4` → **Atlas → Atlas Settings**៖ Coverage layer `Kh_Province_Boundary` · Page name `Name_KH`។
2. ជ្រើសប្រអប់ផែនទី → Item Properties → ធីក **Controlled by atlas** · Margin around feature `10%`។
3. បន្ថែម Label ជាមួយកន្សោម៖

    ```text
    'ខេត្ត ' || attribute(@atlas_feature, 'Name_KH')
    ```

4. **Atlas → Preview Atlas** ហើយរំកិលមើលសន្លឹកនីមួយៗ។ Export Atlas as PDF (ឯកសារតែមួយ ឬមួយសន្លឹកក្នុងមួយឯកសារ)។

## សកម្មភាពទី៤៖ នាំចេញ និងពិនិត្យ · ១៥ នាទី

1. នាំចេញ `report_a4` ជា PDF ៣០០ dpi និង PNG ១៥០ dpi។
2. បោះពុម្ពទំហំពិត ១០០% (មិនមែន Fit to page)។ វាស់របារមាត្រដ្ឋានដោយបន្ទាត់ ដើម្បីផ្ទៀងផ្ទាត់មាត្រដ្ឋាន។
3. អនុវត្តបញ្ជីត្រួតពិនិត្យប្រាំបីពី[មេរៀនទី១៤](../lessons/lesson-14.md)។
