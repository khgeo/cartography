# មគ្គុទ្ទេសក៍ឌីជីថលទី៤៖ Google Earth និង Google Maps

ឧបករណ៍ទាំងពីរមានតួនាទីខុសគ្នា។ Google Earth សមសម្រាប់មើលរូបភាពអាកាស បង្កើត point/line/polygon បង្ហាញ profile និងស្វែងយល់ទេសភាព។ Google Maps សមសម្រាប់ស្វែងរកកន្លែង ផ្លូវ និងរៀបចំបញ្ជី។ ទាំងពីរជាប្រភពជំនួយ—not an authoritative survey record។

## ១. លំហូរ Google Earth សម្រាប់ការសង្កេត

1. ស្វែងរកតំបន់ និងកត់កាលបរិច្ឆេទ imagery ប្រសិនបើបង្ហាញ។
2. បង្កើត point សម្រាប់សញ្ញាសម្គាល់, line សម្រាប់ផ្លូវ និង polygon សម្រាប់តំបន់។
3. ប្រើឈ្មោះស្តង់ដារ និង description ដែលមានប្រភព/ថ្ងៃ។
4. មើល elevation profile របស់ line; កម្ពស់ពី imagery/terrain មិនជំនួសការវាស់ survey។
5. Export KML/KMZ ហើយពិនិត្យក្នុង QGIS។

## ២. Digitizing គឺការបកស្រាយ

មនុស្សពីរអាចគូសដំបូលអគារដូចគ្នាខុសគ្នា ព្រោះស្រមោល គែមមិនច្បាស់ និងការជ្រើស scale។ មុនគូស ត្រូវកំណត់៖ វត្ថុអ្វីជាគោល គូសតាមគែមណា zoom ប៉ុន្មាន និងកំហុសអតិបរមាប៉ុន្មាន។ រក្សាទុក `imagery_date`, `digitized_by`, `rule`, `confidence`។

## ៣. Georeferencing ផែនទីស្កេន

ជ្រើស control points ដែលសម្គាល់បានទាំងលើផែនទីចាស់ និង imagery៖ ផ្លូវប្រសព្វ ស្ពាន ជ្រុងអគារចាស់។ ចែកចាយពេញផ្ទៃ; កុំដាក់នៅជ្រុងតែមួយ។ ពិនិត្យ residual ជាចំណុចៗ មិនមើល RMSE តែមួយលេខទេ។ ស្ទឹង និងច្រាំងអាចផ្លាស់ទី ដូច្នេះមិនមែន control point ល្អជានិច្ច។

## ៤. Google Maps និង offline planning

រកកន្លែង បង្កើតបញ្ជីផ្លូវ និងទាញតំបន់ offline មុនធ្វើដំណើរ។ Offline map អាចមានកាលផុតកំណត់ ឬខ្វះមុខងារ ដូច្នេះយកផែនទីបម្រុង និងកូអរដោនេគោលដៅ។ ព័ត៌មានអាជីវកម្ម និងផ្លូវអាចត្រូវបានកែដោយសហគមន៍; បញ្ជាក់ជាមួយប្រភពមូលដ្ឋានសម្រាប់ការសម្រេចចិត្តសំខាន់។

## ៥. QGIS comparison exercise

គូស polygon តែមួយដោយសិស្សបីនាក់ពី imagery ដូចគ្នា។ នាំ KML ទៅ QGIS, បម្លែងជា GeoPackage, គណនាផ្ទៃ និង overlay។ ពិភាក្សាថា variation កើតពី interpretation, zoom ឬ snapping។ បន្ទាប់មកបង្កើត rule រួម ហើយគូសឡើងវិញ។
