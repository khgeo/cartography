# លំហាត់ទី១៣៖ ស្លាក និងអក្សរខ្មែរលើផែនទី

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៣៖ អក្សរ និងការដាក់ស្លាកលើផែនទី](../lessons/lesson-13.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ៩០ នាទី

## ស្ថានភាព

ផែនទីខេត្តរបស់អ្នកមានទិន្នន័យល្អ ប៉ុន្តែស្លាកជាន់គ្នា។ អ្នកនឹងរៀបចំស្លាកឡើងវិញ ដោយប្រើឋានានុក្រម ស្រទាប់ស អាទិភាព និងខ្សែយោង ហើយពិនិត្យអក្សរខ្មែរក្នុង PDF។

## គោលបំណង

- កំណត់ស្លាកតាមឋានានុក្រម និងតាមមាត្រដ្ឋាន។
- ប្រើ Placement Buffer Priority និង Callouts។
- ដាក់ស្លាកតាមខ្សែសម្រាប់ទន្លេ។
- ពិនិត្យអក្សរខ្មែរនៅទំហំពិត និងក្នុង PDF។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

| ស្រទាប់ | ថត | វាល |
|---|---|---|
| `Kh_Province_Boundary` | `Admin/` | `Name_KH` `POP2017` |
| `Kh_Commune_area` | `Admin/` | `COM_NAME` |
| `Kh_Lake_n_Mekong` · `Kh_Stream` | `Water/` | |
| `Census_Village` | `Census_2008/` | `TOTPOP` |

## ពិសោធន៍មុនចាប់ផ្ដើម · ១០ នាទី

## សកម្មភាពទី១៖ ស្លាកខេត្ត និងឋានានុក្រម · ២០ នាទី

1. `Kh_Province_Boundary` → **Labels → Single Labels** · Value `Name_KH` · Font **Battambang** ៨,៥ pt។
2. **Buffer**៖ ធីក · ទំហំ ០,៨ មម · ពណ៌ស។
3. បង្កើតឋានានុក្រមដោយ **Rule-based labelling**៖

    | ច្បាប់ | កន្សោម | ទំហំ |
    |---|---|---|
    | រាជធានី និងខេត្តធំ | `"POP2017" > 900000` | ១០ pt ដិត |
    | ខេត្តផ្សេង | `ELSE` | ៨,៥ pt |

4. ពិនិត្យលទ្ធផល ហើយកត់ត្រាចំនួនស្លាកដែល QGIS លាក់ (Labels → Rendering → Show all labels សម្រាប់ស្រទាប់ ដើម្បីប្រៀបធៀប)។

## សកម្មភាពទី២៖ ស្លាកទន្លេ · ១៥ នាទី

1. `Kh_Lake_n_Mekong` ឬ `Kh_Stream` → Labels · Placement **Curved** · Position **Above line**។
2. Font៖ អក្សរទ្រេត ពណ៌ `#0d47a1` ទំហំ ៨ pt · Buffer ស ០,៨ មម។
3. ធីក **Repeat labels** រៀងរាល់ ៨០ មម សម្រាប់ខ្សែវែង។

## សកម្មភាពទី៣៖ ខ្សែយោង និងអាទិភាព · ២០ នាទី

1. សម្រាប់ខេត្តតូចជុំវិញភ្នំពេញ បើក **Callouts** (Labels → Callouts → Simple lines) ហើយកំណត់ **Draw lines to label** ។
2. Labels → Rendering → **Priority**៖ កំណត់ខេត្ត `8` · ទន្លេ `4` · ភូមិ `2`។
3. បន្ថែមស្លាកភូមិពី `Census_Village` ដោយត្រង `"TOTPOP" > 3000` និង **Scale dependent visibility** ចាប់ពី ១:៥០០ ០០០ ចុះក្រោម។

## សកម្មភាពទី៤៖ ពិនិត្យអក្សរខ្មែរ · ២០ នាទី

1. នាំចេញ PDF ៣០០ dpi។ បើកក្នុងកម្មវិធីអាន PDF ហើយពង្រីក ៤០០%។
2. ពិនិត្យឈ្មោះដែលមានជើង និងស្រៈច្រើន៖ «ព្រះវិហារ» «ត្បូងឃ្មុំ» «បន្ទាយមានជ័យ» «កំពង់ស្ពឺ»។
3. សាកល្បងពុម្ពអក្សរពីរ (ឧ. Battambang និង Khmer OS Siemreap) ហើយប្រៀបធៀបនៅ ៧ pt និង ៩ pt។
4. បំពេញតារាង៖

    | ពុម្ពអក្សរ | ៧ pt | ៩ pt | បញ្ហាដែលឃើញ |
    |---|---|---|---|
    | | | | |

**សំណួរ៖** ទំហំអប្បបរមាណាដែលអ្នកនឹងណែនាំសម្រាប់ស្លាកខ្មែរលើផែនទីបោះពុម្ព?

## សកម្មភាពទី៥៖ ផែនទីចុងក្រោយ · ១៥ នាទី

ធ្វើប្លង់ A4 ជាមួយស្លាកដែលរៀបចំរួច រួចនាំចេញ PDF។ សរសេរ ៣ ប្រយោគ៖ ស្លាកណាដែលអ្នកលុប និងហេតុអ្វី។

## លទ្ធផលត្រូវប្រគល់

- គម្រោង QGIS ជាមួយ Rule-based labelling។
- PDF ចុងក្រោយ និងរូបថតអេក្រង់ការពង្រីក ៤០០%។
- តារាងប្រៀបធៀបពុម្ពអក្សរ និងការពន្យល់។
