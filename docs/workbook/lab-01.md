# លំហាត់ទី១៖ ផែនទីដំបូងរបស់ខ្ញុំ៖ ផែនទីយោង និងផែនទីប្រធានបទនៃកម្ពុជា

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី១៖ ផែនទី និងដំណើរការធ្វើផែនទី](../lessons/lesson-01.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ១០០ នាទី

## ស្ថានភាព

សាលារៀនមួយសុំផែនទីពីរសម្រាប់ដាក់ក្នុងថ្នាក់៖ **ផែនទីយោង** ដែលសិស្សប្រើរកខេត្ត ទន្លេ និងផ្លូវជាតិ និង **ផែនទីប្រធានបទ** ដែលបង្ហាញតំបន់ភូមិសាស្ត្រទាំងប្រាំរបស់កម្ពុជា។ ទិន្នន័យដូចគ្នា ប៉ុន្តែគោលបំណងខុសគ្នា ដូច្នេះការសម្រេចចិត្តផែនទីវិទ្យាក៏ខុសគ្នាដែរ។

## គោលបំណង

- វាយតម្លៃផែនទីដោយប្រើបញ្ជីត្រួតពិនិត្យធាតុផែនទី។
- បន្ថែមស្រទាប់ តម្រៀបលំដាប់ និងកំណត់និមិត្តសញ្ញាមូលដ្ឋានក្នុង QGIS។
- រៀបចំប្លង់ផែនទី (Print Layout) ដែលមានធាតុសំខាន់ៗ ហើយនាំចេញជា PDF។
- ប្រៀបធៀបការសម្រេចចិត្តរវាងផែនទីយោង និងផែនទីប្រធានបទ។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

| `Kh_Province_Center` | `Admin/` | ទីរួមខេត្ត |
| `Kh_Lake_n_Mekong` | `Water/` | បឹងទន្លេសាប និងទន្លេធំៗ |
| `Kh_Main_Roads_MPWT2014` | `Infrastructure/` | ផ្លូវជាតិ |

## ពិសោធន៍មុនចាប់ផ្ដើម · ១០ នាទី

<div class="sim" data-sim="map-elements"></div>

បើកធាតុផែនទីម្ដងមួយៗ។ សរសេរធាតុដែលអ្នកគិតថា **ចាំបាច់** សម្រាប់ផែនទីដាក់ក្នុងថ្នាក់ និងធាតុដែល **អាចលុបបាន**។

## សកម្មភាពទី១៖ រៀបចំគម្រោង · ១០ នាទី

1. បង្កើតថត `D:\GIS\carto_lab01\` ហើយរក្សាទុកគម្រោងថ្មីជា `lab01.qgz`។
2. កំណត់ CRS គម្រោងជា **EPSG:32648** (WGS 84 / UTM zone 48N) នៅជ្រុងខាងក្រោមស្ដាំ។ ហេតុផលនឹងសិក្សាក្នុងមេរៀនទី២ និងទី៣។
3. **Project → Properties → General → Save paths → Relative**។

## សកម្មភាពទី២៖ ផែនទីយោង · ២៥ នាទី

1. បន្ថែមស្រទាប់ទាំងប្រាំ ហើយតម្រៀបពីលើចុះក្រោម៖ ទីរួមខេត្ត · ផ្លូវជាតិ · ទឹក · ខេត្ត · ប្រទេសជិតខាង។

    !!! tip "ក្បួនលំដាប់ស្រទាប់"
        ចំណុចនៅលើ · បន្ទាត់នៅកណ្ដាល · ពហុកោណនៅក្រោម។ បើពហុកោណនៅលើ វានឹងលាក់ចំណុច និងបន្ទាត់។

2. កំណត់និមិត្តសញ្ញា (**Layer Properties → Symbology → Single Symbol**)៖

    | ស្រទាប់ | ពណ៌ផ្ទៃ | ពណ៌ព្រំ / បន្ទាត់ | ទំហំ |
    |---|---|---|---|
    | ប្រទេសជិតខាង | `#eeeeee` | `#bdbdbd` | ០,២ មម |
    | ខេត្ត | `#fafaf5` | `#9e9e9e` | ០,៣ មម |
    | ទឹក | `#9ecae1` | `#6baed6` | ០,២ មម |
    | ផ្លូវជាតិ | | `#d84315` | ០,៦ មម |
    | ទីរួមខេត្ត | `#212121` | ពណ៌ស | ២ មម |

3. ដាក់ស្លាកឈ្មោះខេត្ត៖ **Layer Properties → Labels → Single Labels** · Value `Name_KH` · Font **Battambang** ឬ **Khmer OS Siemreap** · ទំហំ ៨ pt · **Buffer** ពណ៌ស ០,៨ មម។
4. ពង្រីកមើលឈ្មោះខេត្ត។ បើអក្សរខ្មែរបែក (ស្រៈ ឬជើងមិនត្រូវកន្លែង) ត្រូវប្ដូរពុម្ពអក្សរ។

**សំណួរ៖** ហេតុអ្វីផ្ទៃខេត្តប្រើពណ៌ស្រាល ឯផ្លូវជាតិប្រើពណ៌ដិត? ធាតុណាដែលអ្នកចង់ឲ្យភ្នែកឃើញមុនគេ?

## សកម្មភាពទី៣៖ ប្លង់ផែនទី និងការនាំចេញ · ៣០ នាទី

1. **Project → New Print Layout** · ឈ្មោះ `reference_map` · ទំហំ **A4 Landscape** (ចុចស្ដាំលើផ្ទៃក្រដាស → Page Properties)។
2. **Add Map**៖ គូសប្រអប់ផែនទីធំ។ ក្នុង Item Properties កំណត់ Scale ប្រហែល `1:3000000`។
3. បន្ថែមធាតុ៖

    | ធាតុ | ឧបករណ៍ | ការកំណត់ |
    |---|---|---|
    | ចំណងជើង | Add Label | «ផែនទីរដ្ឋបាលកម្ពុជា» · Battambang ២០ pt |
    | តារាងសម្គាល់ | Add Legend | បិទ Auto update · លុបស្រទាប់ប្រទេសជិតខាង · ប្ដូរឈ្មោះជាខ្មែរ |
    | របារមាត្រដ្ឋាន | Add Scale Bar | Units **Kilometers** · Fixed width `50` · Segments ២ ស្ដាំ ០ ឆ្វេង |
    | ទិសខាងជើង | Add North Arrow | ទំហំតូច នៅជ្រុង |
    | ប្រភព | Add Label | «ប្រភព៖ Kh_Province_Boundary · MPWT 2014 · EPSG:32648 · ឈ្មោះអ្នកធ្វើ · ២០២៦» |

4. **Layout → Export as PDF** · Resolution **300 dpi** → `reference_map.pdf`។ នាំចេញជា PNG ផងដែរ។
5. បើក PDF ហើយពិនិត្យថា អក្សរខ្មែរត្រឹមត្រូវ និងរបារមាត្រដ្ឋានអានបាន។

## សកម្មភាពទី៤៖ ផែនទីប្រធានបទ · ២០ នាទី

1. ចម្លងស្រទាប់ `Kh_Province_Boundary` (Duplicate Layer) ហើយប្ដូរឈ្មោះជា `តំបន់ភូមិសាស្ត្រ`។
2. **Symbology → Categorized** · Value `Zone_Sch` · ចុច **Classify** · ជ្រើសពណ៌ផ្សេងៗគ្នាដែលមិនដិតពេក។
3. បិទស្រទាប់ផ្លូវជាតិ និងទីរួមខេត្ត។ ផែនទីប្រធានបទត្រូវការតែអ្វីដែលជួយប្រធានបទ។
4. ក្នុង Layout Manager ចម្លង `reference_map` ជា `zones_map`។ ក្នុងប្រអប់ផែនទី ធីក **Lock layers** បន្ទាប់ពីកំណត់ស្រទាប់ ដើម្បីកុំឲ្យប្លង់ទីមួយប្ដូរ។
5. ប្ដូរចំណងជើងជា «តំបន់ភូមិសាស្ត្រទាំងប្រាំនៃកម្ពុជា» និងធ្វើបច្ចុប្បន្នភាពតារាងសម្គាល់ → នាំចេញ `zones_map.pdf`។
