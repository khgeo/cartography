## ស្ថានភាព

ក្រុមវិស្វកម្មត្រូវជ្រើសផ្លូវសម្រាប់បណ្ដាញទឹកស្អាតទៅភូមិនៅជើងភ្នំ។ អ្នកត្រូវអានផែនទីទីសណ្ឋាន គណនាជម្រាល គូសផ្នែកកាត់បញ្ឈរ ហើយបង្កើតផែនទីរលកដីក្នុង QGIS។

## គោលបំណង

- អានកម្ពស់ ជម្រាល និងលេខយោងក្រឡាពីផែនទីទីសណ្ឋាន។
- បង្កើតខ្សែវណ្ឌ ស្រមោលភ្នំ និងផ្នែកកាត់បញ្ឈរក្នុង QGIS។
- ដាក់ពណ៌តាមកម្ពស់ និងបញ្ចូលខ្សែវណ្ឌលើស្រមោលភ្នំ។

## សកម្មភាពទី១៖ អានផែនទីក្រដាស · ២៥ នាទី

បើកផែនទីគំរូ (JPG) ហើយឆ្លើយ៖

1. ចន្លោះខ្សែវណ្ឌប៉ុន្មានម៉ែត្រ? ខ្សែវណ្ឌគោលរៀងរាល់ប៉ុន្មាន?
2. ប៉ាន់ស្មានកម្ពស់នៃភូមិ V2 V3 និង V4 (ជិតបំផុតទៅខ្សែវណ្ឌណា?)។
3. កម្ពស់ខ្ពស់បំផុតលើផែនទីប្រហែលប៉ុន្មាន?
4. សរសេរលេខយោងក្រឡា ៦ ខ្ទង់នៃភូមិ V2។
5. រកជ្រលងមួយ និងជួរភ្នំមួយ ដោយប្រើក្បួន V។

!!! tip "អានលេខយោង"
    ខ្សែក្រឡាមានលេខជាគីឡូម៉ែត្រ (ឧ. `404` = E ៤០៤ ០០០ ម)។ សម្រាប់លេខ ៦ ខ្ទង់ យក ៣ ខ្ទង់នៃ Easting (គីឡូម៉ែត្រ + ១០០ ម) រួច ៣ ខ្ទង់នៃ Northing។

## សកម្មភាពទី២៖ ខ្សែវណ្ឌពី DEM · ២៥ នាទី

1. បន្ថែម `dem_sample_synthetic.tif`។ ពិនិត្យ Layer Properties → Information៖ CRS ទំហំក្រឡា និងជួរតម្លៃ។
2. **Raster → Extraction → Contour**៖ Interval `20` · Attribute name `ELEV` → `contours_20m.gpkg`
3. ធ្វើម្ដងទៀតជាមួយ Interval `100` → `contours_100m.gpkg` (ខ្សែវណ្ឌគោល)។
4. និមិត្តសញ្ញា៖ `contours_20m` ខ្សែស្ដើងពណ៌ត្នោត · `contours_100m` ខ្សែក្រាស់ជាង ព្រមទាំង **Labels** ពីវាល `ELEV`។

## សកម្មភាពទី៣៖ ស្រមោលភ្នំ និងពណ៌តាមកម្ពស់ · ២៥ នាទី

1. **Raster → Analysis → Hillshade**៖ Azimuth `315` · Altitude `45` · Z factor `1` → `hillshade.tif`
2. ក្នុង Layer Properties នៃ DEM ជ្រើស **Singleband pseudocolor** ជាមួយ Color ramp បៃតង → ត្នោត (ពណ៌តាមកម្ពស់)។
3. ដាក់ DEM ពណ៌នៅលើ `hillshade` ហើយកំណត់ **Blending mode = Multiply** ឬ Opacity ៦០%។
4. ដាក់ខ្សែវណ្ឌ ស្ទឹង និងភូមិនៅលើគេ។

**សំណួរ៖** ការបញ្ចូលស្រមោលភ្នំជាមួយពណ៌តាមកម្ពស់ ជួយអ្នកអានយ៉ាងណា ធៀបនឹងខ្សែវណ្ឌតែឯង?

## សកម្មភាពទី៤៖ ផ្នែកកាត់បញ្ឈរ · ១៥ នាទី

1. ដំឡើងកម្មវិធីជំនួយ **Profile Tool** (Plugins → Manage and Install Plugins)។ ក្នុង QGIS 3.34 អាចប្រើ **Elevation Profile** (View → Elevation Profile) ក៏បាន។
2. កំណត់ DEM ជាប្រភពកម្ពស់ (Layer Properties → Elevation → Represents Terrain)។
3. គូសខ្សែពីភូមិ V2 ទៅ V3 ហើយអានផ្នែកកាត់បញ្ឈរ។ កត់ត្រាកម្ពស់អតិបរមា និងជម្រាលចោតបំផុត។

## សកម្មភាពទី៥៖ ផែនទីរលកដី · ២០ នាទី

បង្កើត Print Layout A4 ដែលមាន៖ ស្រមោលភ្នំ + ពណ៌តាមកម្ពស់ + ខ្សែវណ្ឌគោលមានលេខ + ស្ទឹង + ភូមិ + ចំណងជើង + សញ្ញាសម្គាល់ផែនទី + របារមាត្រដ្ឋាន + ប្រភព (ចំណាំថាកម្ពស់ជាតម្លៃសំយោគ) → នាំចេញ PDF។
