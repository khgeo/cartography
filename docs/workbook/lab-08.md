# លំហាត់ទី៨៖ ពណ៌ ឈុតពណ៌ និងការពិនិត្យភាពងាយស្រួលអាន

!!! info "ព័ត៌មានលំហាត់"
    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៨៖ ពណ៌ក្នុងផែនទីវិទ្យា](../lessons/lesson-08.md)
    **ការអនុវត្តដោយខ្លួនឯង** · QGIS 3.34 LTR · ប្រហែល ៩០ នាទី

## ស្ថានភាព

ផែនទីដង់ស៊ីតេរបស់អ្នកនឹងត្រូវបោះពុម្ពក្នុងរបាយការណ៍សខ្មៅ និងបង្ហាញលើប្រាជេក់ទ័រ។ អ្នកត្រូវជ្រើសឈុតពណ៌ដែលដំណើរការទាំងពីរករណី ហើយសម្រាប់អ្នកអានដែលមានភ្នែកខ្វះពណ៌។

## គោលបំណង

- ប្រើឈុតពណ៌ ColorBrewer ក្នុង QGIS និងបង្កើតឈុតផ្ទាល់ខ្លួន។
- ជ្រើសឈុតតគ្នា ពីរទិស និងប្រភេទតាមទិន្នន័យ។
- ពិនិត្យផែនទីសម្រាប់ភ្នែកខ្វះពណ៌ និងសម្រាប់ការបោះពុម្ពសខ្មៅ។
- កំណត់ពណ៌សម្រាប់ «គ្មានទិន្នន័យ»។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

|---|---|---|
| `Kh_Province_Boundary` | `Admin/` | `Density` `POP2017` |
| `Kh_Landuse2003` | `Landuse/` | `CATEGORY` |
| `Kh_Commune_area` | `Admin/` | |

## ពិសោធន៍មុនចាប់ផ្ដើម · ១០ នាទី

## សកម្មភាពទី១៖ ឈុតតគ្នា និងឈុតឥន្ធនូ · ២០ នាទី

1. `Kh_Province_Boundary` → Graduated លើ `Density` · Natural Breaks · ៥ ថ្នាក់។
2. សាកល្បង Color ramp បី៖ **Reds** (តគ្នា) · **Spectral** (ឥន្ធនូ) · **Viridis**។
3. សម្រាប់នីមួយៗ សួរខ្លួនឯង៖ តើថ្នាក់ខ្ពស់បំផុតលេចធ្លោឬទេ? តើលំដាប់អានបានពីសញ្ញាសម្គាល់ផែនទីទេ?

!!! tip "ColorBrewer ក្នុង QGIS"
    ក្នុងបញ្ជី Color ramp ចុច **Create New Color Ramp → Catalog: ColorBrewer** ហើយជ្រើសប្រភេទ (Sequential · Diverging · Qualitative) និងចំនួនថ្នាក់។

## សកម្មភាពទី២៖ ឈុតពីរទិស · ២០ នាទី

1. Field Calculator លើ `Kh_Province_Boundary`៖

    ```text
    "Density" - 199
    ```

    ដាក់ឈ្មោះវាល `dens_diff` (ភាពខុសពីមធ្យមជាតិ)។

2. Graduated លើ `dens_diff` · ៥ ថ្នាក់ · Color ramp **RdBu** ឬ **BrBG** (ពីរទិស)។
3. កែព្រំថ្នាក់ឲ្យស៊ីមេទ្រីជុំវិញសូន្យ ឧទាហរណ៍ `-200 · -50 · 0 · 50 · 200`។

**សំណួរ៖** ហេតុអ្វីឈុតពីរទិសត្រូវការចំណុចកណ្ដាលច្បាស់លាស់? តើសូន្យនៅទីនេះមានន័យអ្វី?

## សកម្មភាពទី៣៖ ឈុតប្រភេទ និងគ្មានទិន្នន័យ · ២០ នាទី

1. បន្ថែម `Kh_Landuse2003` → **Categorized** លើ `CATEGORY` → Classify។
2. ជ្រើស Color ramp **ColorBrewer Set2** ឬកំណត់ពណ៌ដោយដៃតាមការរំពឹងទុក៖ ព្រៃ = បៃតង · ទឹក = ខៀវ · ទីក្រុង = ក្រហម/ប្រផេះ · ដី = ត្នោត។
3. ក្នុងផ្ទាំង Categorized បន្ថែមថ្នាក់ **all other values** ហើយកំណត់ពណ៌ប្រផេះស្រាល ជាមួយស្លាក «គ្មានទិន្នន័យ»។

## សកម្មភាពទី៤៖ ពិនិត្យភាពងាយស្រួលអាន · ២០ នាទី

1. នាំចេញផែនទីដង់ស៊ីតេ (ឈុត Reds) ជា PNG។
2. បើករូបភាពក្នុងកម្មវិធីរូបភាព ហើយបម្លែងជា **Grayscale**។ តើថ្នាក់ទាំង ៥ នៅតែបែងចែកបានឬទេ?
3. ធ្វើដូចគ្នាជាមួយផែនទីឈុត Spectral។ ប្រៀបធៀប។
4. ត្រឡប់ទៅពិសោធន៍ខាងលើ ហើយពិនិត្យឈុតទាំងពីរក្នុង Deuteranopia។
5. បំពេញតារាង៖

    | ឈុតពណ៌ | អានបានពេលសខ្មៅ | អានបានពេល Deuteranopia | សេចក្ដីសន្និដ្ឋាន |
    |---|---|---|---|
    | Reds | | | |
    | Spectral | | | |
    | Viridis | | | |

## សកម្មភាពទី៥៖ ផែនទីចុងក្រោយ · ១០ នាទី

ធ្វើផែនទី A4 ដោយប្រើឈុតពណ៌ដែលអ្នកជ្រើស ជាមួយសញ្ញាសម្គាល់ផែនទីដែលមានឯកតា និងពណ៌សម្រាប់ «គ្មានទិន្នន័យ» → នាំចេញ PDF។

## លទ្ធផលត្រូវប្រគល់

- ផែនទីបីជាមួយឈុតពណ៌ខុសគ្នា និងកំណែសខ្មៅ។
- ផែនទីឈុតពីរទិសជាមួយព្រំស៊ីមេទ្រី។
- តារាងពិនិត្យភាពងាយស្រួលអាន និងផែនទី A4 ចុងក្រោយ។
