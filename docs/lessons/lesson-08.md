# មេរៀនទី៨៖ ពណ៌ក្នុងផែនទីវិទ្យា

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៨ ក្នុងចំណោម ១៥

ពណ៌ជាឧបករណ៍ដ៏មានឥទ្ធិពលបំផុត និងងាយប្រើខុសបំផុតក្នុងផែនទីវិទ្យា។ ពណ៌ត្រឹមត្រូវធ្វើឲ្យលំនាំលេចឡើងភ្លាមៗ។ ពណ៌ខុសបង្កើតព្រំក្លែងក្លាយ លាក់លំនាំ ឬធ្វើឲ្យអ្នកអានប្រហែល ៥% មើលមិនឃើញអ្វីសោះ។

មេរៀននេះពន្យល់វិមាត្រនៃពណ៌ ឈុតពណ៌បីប្រភេទ ភ្នែកខ្វះពណ៌ អត្ថន័យវប្បធម៌ និងភាពខុសគ្នារវាងអេក្រង់ និងការបោះពុម្ព។

## ៨.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់វិមាត្របីនៃពណ៌៖ ពណ៌ តម្លៃពន្លឺ និងភាពឆ្អែត។
2. ជ្រើសឈុតពណ៌តគ្នា ពីរទិស ឬប្រភេទ តាមទិន្នន័យ។
3. ពិនិត្យផែនទីសម្រាប់អ្នកខ្វះពណ៌ និងសម្រាប់ការបោះពុម្ពសខ្មៅ។
4. ពន្យល់ហេតុអ្វីឈុតឥន្ធនូបង្កើតបញ្ហាសម្រាប់ទិន្នន័យបរិមាណ។
5. ប្រើ ColorBrewer និងឧបករណ៍ពិនិត្យពណ៌។

## ៨.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីដែលបុរសម្នាក់ក្នុងចំណោម ២០ មើលមិនយល់

ក្រុមការងារមួយធ្វើផែនទីហានិភ័យទឹកជំនន់ ដោយប្រើពណ៌ **បៃតង → លឿង → ក្រហម** ដែលមើលទៅច្បាស់ណាស់លើអេក្រង់។

ពេលបង្ហាញក្នុងសិក្ខាសាលា អ្នកចូលរួមម្នាក់និយាយថា គាត់មិនអាចបែងចែកតំបន់បៃតង និងក្រហមបានទេ។ គាត់មានភ្នែកខ្វះពណ៌បៃតង–ក្រហម ដែលប៉ះពាល់ប្រុសប្រហែល ៥% (ប្រហែលម្នាក់ក្នុងចំណោម ២០)។ ពេលបោះពុម្ពសខ្មៅ ផែនទីក៏មិនអានបានដែរ ព្រោះបៃតង និងក្រហមមានតម្លៃពន្លឺស្ទើរស្មើគ្នា។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- តើត្រូវជ្រើសឈុតពណ៌យ៉ាងណាសម្រាប់ទិន្នន័យបរិមាណ?
- តើពិនិត្យផែនទីសម្រាប់អ្នកខ្វះពណ៌ដោយរបៀបណា?
- តើពណ៌ត្រូវប្ដូរយ៉ាងណារវាងអេក្រង់ និងការបោះពុម្ព?

## ៨.៣. ទ្រឹស្ដីស្នូល

### ៨.៣.១. វិមាត្របីនៃពណ៌

ពណ៌មានវិមាត្របីដែលភ្នែកអានខុសគ្នា៖

<figure markdown>
--8<-- "assets/svg/c08-dimensions.svg"
<figcaption>រូបទី៨.១៖ វិមាត្របីនៃពណ៌។ ការប្ដូរពណ៌បង្កើតភាពខុសគ្នាដោយគ្មានលំដាប់ ឯការប្ដូរតម្លៃពន្លឺ ឬភាពឆ្អែតបង្កើតលំដាប់ដែលភ្នែកអានបាន។</figcaption>
</figure>

| វិមាត្រ | អត្ថន័យ | បង្ហាញអ្វី |
|---|---|---|
| **ពណ៌ (Hue)** | ក្រហម ខៀវ បៃតង | **ភាពខុសគ្នា** (ប្រភេទ) |
| **តម្លៃពន្លឺ (Value)** | ស្រាល ↔ ដិត | **លំដាប់ និងបរិមាណ** |
| **ភាពឆ្អែត (Saturation)** | ស្លេក ↔ ឆ្អែត | លំដាប់ខ្សោយ · ការទាញចំណាប់អារម្មណ៍ |

ក្បួនស្នូល៖ **ប្រើតម្លៃពន្លឺសម្រាប់ «ច្រើន ឬតិច» និងប្រើពណ៌សម្រាប់ «ខុសគ្នា»**។ នេះជាមូលហេតុដែលផែនទី choropleth ល្អ ប្រើពណ៌តែមួយ ស្រាល → ដិត។

នៅក្នុងកម្មវិធី ពណ៌តំណាងដោយ **RGB** (អេក្រង់ ០–២៥៥) ឬ **HSV/HSL** (ងាយកែតម្លៃពន្លឺ) ឯការបោះពុម្ពប្រើ **CMYK**។

### ៨.៣.២. ឈុតពណ៌បីប្រភេទ

ColorBrewer (colorbrewer2.org) របស់ Cynthia Brewer បែងចែកឈុតពណ៌ជាបីប្រភេទ៖

<figure markdown>
--8<-- "assets/svg/c08-schemes.svg"
<figcaption>រូបទី៨.២៖ ឈុតពណ៌បួនប្រភេទ និងករណីប្រើប្រាស់។ ឈុតឥន្ធនូមើលទៅស្អាត ប៉ុន្តែបង្កើតព្រំក្លែងក្លាយ និងបាត់លំដាប់សម្រាប់អ្នកអានជាច្រើន។</figcaption>
</figure>

- **តគ្នា (Sequential)**៖ ពណ៌តែមួយ ស្រាល → ដិត សម្រាប់បរិមាណទិសតែមួយ។
- **ពីរទិស (Diverging)**៖ ពណ៌ពីរ ជួបគ្នានៅតម្លៃកណ្ដាលដែលមានអត្ថន័យ (សូន្យ មធ្យម គោលដៅ)។
- **ប្រភេទ (Qualitative)**៖ ពណ៌ខុសគ្នាដោយគ្មានលំដាប់ សម្រាប់ទិន្នន័យប្រភេទ។

**ឈុតឥន្ធនូ (Rainbow)** មិនស្ថិតក្នុងបីនេះទេ។ វាបង្កើតបញ្ហា៖ ភ្នែកមើលឃើញព្រំនៅកន្លែងដែលទិន្នន័យមិនប្ដូរ (ឧ. ត្រង់លឿង) · គ្មានលំដាប់តម្លៃពន្លឺ · បាត់អត្ថន័យសម្រាប់អ្នកខ្វះពណ៌ និងពេលបោះពុម្ពសខ្មៅ។

!!! example "ពិសោធន៍៖ ឈុតពណ៌ និងភ្នែកខ្វះពណ៌"
    ប្ដូរឈុតពណ៌ រួចប្ដូរជម្រើស «ភ្នែក» ទៅ Deuteranopia។ ឈុតណាដែលនៅតែអានបាន ហើយឈុតណាដែលថ្នាក់លាយបញ្ចូលគ្នា?

### ៨.៣.៣. ភ្នែកខ្វះពណ៌ និងភាពងាយស្រួលអាន

ភ្នែកខ្វះពណ៌ (Colour vision deficiency) ប៉ះពាល់៖

| ប្រភេទ | ពិពណ៌នា | ប្រេវ៉ាឡង់ប្រហាក់ប្រហែល |
|---|---|---|
| Deuteranopia / Deuteranomaly | ខ្វះការយល់ពណ៌បៃតង | ច្រើនជាងគេ · ប្រុសប្រហែល ៥% |
| Protanopia / Protanomaly | ខ្វះការយល់ពណ៌ក្រហម | ប្រុសប្រហែល ១% |
| Tritanopia | ខ្វះការយល់ពណ៌ខៀវ | កម្រណាស់ |

ក្បួនសុវត្ថិភាព៖

1. **កុំពឹងលើពណ៌តែម្នាក់ឯង**៖ បន្ថែមភាពខុសគ្នានៃតម្លៃពន្លឺ លំនាំ ឬស្លាក។
2. **ជៀសវាងបៃតង–ក្រហមជាគូផ្ទុយ**។ ប្រើខៀវ–ទឹកក្រូចវិញ។
3. **ប្រើឈុត ColorBrewer ដែលមានសញ្ញា «colorblind safe»**។
4. **សាកល្បង**៖ ពិសោធន៍ខាងលើ · ឧបករណ៍អនឡាញ · ឬបម្លែងជាសខ្មៅ។

ការបោះពុម្ពសខ្មៅ ជាការសាកល្បងដ៏ល្អ៖ បើថ្នាក់នៅតែបែងចែកបានពេលគ្មានពណ៌ ផែនទីនោះមានតម្លៃពន្លឺល្អ។

### ៨.៣.៤. អត្ថន័យវប្បធម៌ និងការរំពឹងទុក

អ្នកអានយកអត្ថន័យមកជាមួយពណ៌៖

| ពណ៌ | ការរំពឹងទុកទូទៅលើផែនទី |
|---|---|
| ខៀវ | ទឹក |
| បៃតង | បន្លែ ព្រៃ ដីកសិកម្ម ឬ «សុវត្ថិភាព» |
| ត្នោត | ដី កម្ពស់ |
| ក្រហម | គ្រោះថ្នាក់ ភាពបន្ទាន់ ភាពក្ដៅ |
| ស ឬប្រផេះស្រាល | គ្មានទិន្នន័យ |

ការប្រើពណ៌ខៀវសម្រាប់តំបន់សម្ងួត ឬក្រហមសម្រាប់ «ល្អ» បង្កើតការភ័ន្តច្រឡំ។ **ពណ៌សម្រាប់ «គ្មានទិន្នន័យ»** ត្រូវខុសពីឈុតទាំងស្រុង (ជាធម្មតាប្រផេះ ឬបន្ទាត់ទ្រេត) ហើយត្រូវមានក្នុងសញ្ញាសម្គាល់ផែនទី។

សូមចំណាំថាអត្ថន័យវប្បធម៌ប្រែប្រួលតាមបរិបទ ដូច្នេះការសាកល្បងជាមួយអ្នកអានពិត សំខាន់ជាងការសន្មត។

### ៨.៣.៥. ពណ៌លើអេក្រង់ និងលើក្រដាស

| បញ្ហា | ដំណោះស្រាយ |
|---|---|
| ពណ៌ដិតលើអេក្រង់ ស្លេកលើក្រដាស | សាកល្បងបោះពុម្ពគំរូ ១០០% មុនផលិតច្រើន |
| ពណ៌ស្រាលពេក បាត់ពេលបោះពុម្ព | រក្សាភាពខុសគ្នានៃតម្លៃពន្លឺយ៉ាងតិច ២០% រវាងថ្នាក់ |
| អេក្រង់ប្រាជេក់ទ័របន្ថយកម្រិតពណ៌ | ប្រើថ្នាក់តិច និងពណ៌ផ្ទុយច្បាស់ |
| ពណ៌ក្នុង PDF ខុសពីអេក្រង់ | នាំចេញជាមួយ profile ពណ៌ដដែល និងពិនិត្យលើម៉ាស៊ីនបោះពុម្ពពិត |

## ៨.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ជួសជុលផែនទីហានិភ័យទឹកជំនន់

ផែនទីដើមប្រើ បៃតង → លឿង → ក្រហម ៥ ថ្នាក់ សម្រាប់កម្រិតហានិភ័យ (បរិមាណ លំដាប់)។

### ជំហានទី១៖ កំណត់ប្រភេទទិន្នន័យ

កម្រិតហានិភ័យមានលំដាប់ (ទាប → ខ្ពស់) ដូច្នេះត្រូវការឈុត **តគ្នា** មិនមែនឈុតឥន្ធនូទេ។

### ជំហានទី២៖ ជ្រើសឈុតថ្មី

ឈុតតគ្នាពណ៌ខៀវ (`#f7fbff` → `#08306b`) ឬពណ៌ក្រហមតែមួយ (`#fef0d9` → `#b30000`)។ ពណ៌ក្រហមសមនឹងការរំពឹងទុក «គ្រោះថ្នាក់» ហើយតម្លៃពន្លឺបង្ហាញលំដាប់។

### ជំហានទី៣៖ ពិនិត្យសម្រាប់អ្នកខ្វះពណ៌

ក្នុងពិសោធន៍ខាងលើ ជ្រើស Deuteranopia។ ឈុតតគ្នាពណ៌តែមួយនៅតែបែងចែកបាន ព្រោះលំដាប់មកពីតម្លៃពន្លឺ មិនមែនពីពណ៌។

### ជំហានទី៤៖ ពិនិត្យសខ្មៅ

បម្លែងផែនទីជាសខ្មៅ (ឬបោះពុម្ពសាកល្បង)។ ឈុតតគ្នាក្លាយជាកម្រិតប្រផេះ ៥ ដែលអានបាន ឯឈុតដើមក្លាយជាប្រផេះស្រដៀងគ្នា។

### ជំហានទី៥៖ បន្ថែមភាពច្បាស់

បន្ថែមស្លាកតម្លៃលើសញ្ញាសម្គាល់ផែនទី · ពណ៌ប្រផេះសម្រាប់ «គ្មានទិន្នន័យ» · និងកំណត់សម្គាល់ថាថ្នាក់ត្រូវបានចាត់តាមវិធីណា។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ការប្ដូរពីឈុតឥន្ធនូទៅឈុតតគ្នាពណ៌តែមួយ ធ្វើឲ្យផែនទីអានបានសម្រាប់អ្នកខ្វះពណ៌ និងពេលបោះពុម្ពសខ្មៅ ដោយមិនបាត់ព័ត៌មានអ្វីទេ។ លំដាប់មកពីតម្លៃពន្លឺ ដែលភ្នែកគ្រប់គ្នាអានបាន។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"

## ៨.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «ពណ៌ច្រើន = ព័ត៌មានច្រើន»**
ពណ៌ច្រើនបំបាត់លំដាប់ ហើយធ្វើឲ្យអ្នកអានពិបាកចាំ។

**២. «ឈុតឥន្ធនូល្អ ព្រោះប្រើក្នុងកម្មវិធីវិទ្យាសាស្ត្រច្រើន»**
ឈុតឥន្ធនូត្រូវបានរិះគន់យ៉ាងទូលំទូលាយ។ ទស្សនាវដ្ដីវិទ្យាសាស្ត្រជាច្រើនឥឡូវណែនាំឈុតដូចជា viridis ឬ ColorBrewer។

**៣. «ភ្នែកខ្វះពណ៌កម្រ ដូច្នេះមិនសំខាន់»**
ក្នុងថ្នាក់រៀន ៤០ នាក់ដែលមានប្រុស ២០ នាក់ ជាធម្មតាមានម្នាក់ដែលមានភ្នែកខ្វះពណ៌។

**៤. «ពណ៌ដដែលមើលទៅដូចគ្នាលើគ្រប់ឧបករណ៍»**
អេក្រង់ ប្រាជេក់ទ័រ និងម៉ាស៊ីនបោះពុម្ពបង្ហាញពណ៌ខុសគ្នា។ ត្រូវសាកល្បងលើឧបករណ៍ចុងក្រោយ។

**៥. «ពណ៌សសម្រាប់តម្លៃទាប និងសម្រាប់ «គ្មានទិន្នន័យ» ក៏បាន»**
អ្នកអាននឹងច្រឡំ។ «គ្មានទិន្នន័យ» ត្រូវមានពណ៌ ឬលំនាំដាច់ដោយឡែក។

## ៨.៩. សំណួររំលឹក និងវាយតម្លៃ

### ក. សំណួរយល់ដឹង

1. រាយវិមាត្របីនៃពណ៌ និងប្រាប់ថាមួយណាបង្ហាញលំដាប់។
2. ពន្យល់ភាពខុសគ្នារវាងឈុតតគ្នា និងឈុតពីរទិស ព្រមទាំងឧទាហរណ៍។
3. ហេតុអ្វីឈុតឥន្ធនូមិនល្អសម្រាប់ទិន្នន័យបរិមាណ?
4. រាយក្បួនបីសម្រាប់ផែនទីដែលអ្នកខ្វះពណ៌អានបាន។
5. ហេតុអ្វី «គ្មានទិន្នន័យ» ត្រូវមានពណ៌ដាច់ដោយឡែក?

### ខ. សំណួរអនុវត្តគោលគំនិត

6. ជ្រើសឈុតពណ៌សម្រាប់៖ (ក) អត្រាអក្ខរកម្មតាមឃុំ (ខ) ការប្រែប្រួលប្រជាជន −២០% ដល់ +៣០% (គ) ប្រភេទក្រប់ដី ៧។
7. ផែនទីទឹកភ្លៀងប្រើក្រហម = ភ្លៀងច្រើន។ ផ្ដល់មតិដោយផ្អែកលើការរំពឹងទុករបស់អ្នកអាន។
8. អ្នកមានផែនទីដែលត្រូវបោះពុម្ពសខ្មៅក្នុងសៀវភៅ។ ពិពណ៌នាការសម្រេចចិត្តពណ៌របស់អ្នក។
9. បន្ទាប់ពីពិនិត្យ Deuteranopia ថ្នាក់ពីរលាយបញ្ចូលគ្នា។ រាយវិធីបីដើម្បីកែ។
10. សរសេរការណែនាំខ្លីៗ (៥ ចំណុច) អំពីពណ៌ សម្រាប់ក្រុមការងារដែលធ្វើផែនទីនៅស្ថាប័នរបស់អ្នក។

### គ. កិច្ចការខ្លី

ជ្រើសផែនទីពណ៌មួយពីអ៊ីនធឺណិត ឬរបាយការណ៍។ កំណត់ឈុតពណ៌ដែលវាប្រើ និងប្រភេទទិន្នន័យ។ ពិនិត្យវាដោយបម្លែងជាសខ្មៅ (កម្មវិធីរូបភាព) ហើយពិពណ៌នាថាតើលំនាំនៅតែអានបានឬទេ។ ស្នើឈុតពណ៌ជំនួសពី ColorBrewer ជាមួយកូដពណ៌។
