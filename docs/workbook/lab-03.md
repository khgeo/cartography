## ស្ថានភាព

អ្នកត្រូវរាយការណ៍ផ្ទៃប្រទេសកម្ពុជា និងធ្វើផែនទីតំបន់អាស៊ីអាគ្នេយ៍។ អ្នកនឹងឃើញថា ចំណោលខុសគ្នា ផ្ដល់ផ្ទៃខុសគ្នា និងរាងប្រទេសខុសគ្នា។

## គោលបំណង

- គណនាផ្ទៃក្នុងចំណោលផ្សេងៗ និងលើអេលីបសូអ៊ីត។
- ប្រៀបធៀបរាងតំបន់ក្នុងចំណោលស៊ីឡាំង ផ្ទៃស្មើ និង UTM។
- កំណត់ CRS គម្រោង និងយល់ On-the-fly reprojection។
- ជ្រើសចំណោលសមស្រប តាមគោលបំណង។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

## សកម្មភាពទី១៖ ផ្ទៃក្នុងចំណោលបួន · ២៥ នាទី

1. បន្ថែម `Kh_Country_area`។ **Project → Properties → General → Ellipsoid**៖ ពិនិត្យថាជា **WGS 84**។
2. Field Calculator បង្កើតវាល Decimal៖

    | វាល | កន្សោម | អត្ថន័យ |
    |---|---|---|
    | `a_ellip` | `$area / 1e6` | ផ្ទៃលើអេលីបសូអ៊ីត (គម²) |
    | `a_utm` | `area($geometry) / 1e6` | ផ្ទៃប្លង់ក្នុង UTM 48N |
    | `a_merc` | `area(transform($geometry,'EPSG:32648','EPSG:3857')) / 1e6` | ផ្ទៃប្លង់ក្នុង Web Mercator |
    | `a_deg` | `area(transform($geometry,'EPSG:32648','EPSG:4326'))` | «ផ្ទៃ» ជាដឺក្រេការ៉េ |

3. គណនាភាគរយខុសពី `a_ellip`៖ `100 * ("a_merc" - "a_ellip") / "a_ellip"`។
4. បំពេញតារាង៖

    | ប្រព័ន្ធ | ផ្ទៃ | ខុសពីអេលីបសូអ៊ីត (%) |
    |---|---:|---:|
    | អេលីបសូអ៊ីត | | ០ |
    | UTM 48N | | |
    | Web Mercator | | |
    | ដឺក្រេ | | គ្មានន័យ |

## សកម្មភាពទី២៖ រាងតំបន់ក្នុងចំណោលផ្សេងៗ · ២៥ នាទី

1. បន្ថែម `Int_Sea` និង `Int_Outside_Cambodia_DIVA`។ និមិត្តសញ្ញា៖ សមុទ្រពណ៌ខៀវ · ប្រទេសពណ៌ប្រផេះ · កម្ពុជាពណ៌ក្រហម។
2. ប្ដូរ CRS គម្រោងម្ដងមួយៗ ហើយថតរូបអេក្រង់ (Export map to image) សម្រាប់នីមួយៗ៖
    - **EPSG:4326** (WGS 84 ជាដឺក្រេ)
    - **EPSG:3857** (Web Mercator)
    - **EPSG:6933** (WGS 84 / NSIDC EASE-Grid 2.0 Global · Equal-Area)
    - **EPSG:32648** (UTM zone 48N)
3. ប្រៀបធៀបរាងឥណ្ឌូនេស៊ី ជប៉ុន និងចិនភាគខាងជើង។ ចំណោលណាដែលធ្វើឲ្យតំបន់ឆ្ងាយពីអេក្វាទ័រធំជាងពិត?

!!! tip "On-the-fly reprojection"
    ពេលប្ដូរ CRS គម្រោង ទិន្នន័យដើមមិនប្ដូរទេ។ QGIS បំប្លែងតែពេលគូសលើអេក្រង់ប៉ុណ្ណោះ។ ពិនិត្យ Layer Properties → Information ដើម្បីបញ្ជាក់ថា CRS ស្រទាប់នៅតែ EPSG:32648។

## សកម្មភាពទី៣៖ ខ្សែតំបន់ UTM · ១៥ នាទី

1. កំណត់ CRS គម្រោងជា EPSG:4326។
2. **View → Decorations → Grid**៖ Interval X `6` · Y `6` · Offset X `0`។ ខ្សែបញ្ឈរនីមួយៗជាព្រំតំបន់ UTM។
3. ពិនិត្យថាកម្ពុជាស្ថិតនៅចន្លោះខ្សែ ១០២° និង ១០៨° ទាំងស្រុងឬទេ។
4. **Vector → Geometry Tools → Extract Vertices** លើ `Kh_Country_area` ហើយរកចំណុចខាងលិចបំផុត និងខាងកើតបំផុត (តម្រៀបតាម `$x` ក្នុង EPSG:4326)។

រក្សាទុកពហុកោណដូចគ្នាជាពីរស្រទាប់៖ EPSG:32648 និង EPSG:3857។ បង្កើតវាល area($geometry)/1000000 ក្នុងស្រទាប់នីមួយៗ។ គណនា $area ជាយោងដោយកំណត់ WGS 84 ellipsoid និងឯកតាផ្ទៃឲ្យច្បាស់។ កុំប្រៀបធៀបលេខដែលមានឯកតាខុសគ្នា។

បើគ្មាន Cambodia.zip ពេញលេញ ប្រើទិន្នន័យសាកល្បងក្នុង [កញ្ចប់អនុវត្ត offline](../appendix/d-offline-practice.md)។ តម្លៃសំយោគមានចម្លើយផ្សេងពីទិន្នន័យដើម៖ កុំប្រើវាដើម្បីឆ្លើយប្រអប់លេខថេរខាងលើ។ ត្រឡប់ទៅ [មេរៀន 3](../lessons/lesson-03.md) ដើម្បីធ្វើពិសោធន៍ និងសំណួរថ្មី។
