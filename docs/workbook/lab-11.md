## ស្ថានភាព

អ្នកត្រូវធ្វើផែនទីពីរ៖ ផែនទីអ៊ីសូលីនពីចំណុចវាស់ និងផែនទីរលកដីដែលផ្សំស្រមោលភ្នំ ពណ៌តាមកម្ពស់ និងខ្សែវណ្ឌ។ គោលដៅគឺឲ្យផែនទីទាំងពីរបង្ហាញភាពមិនច្បាស់ដោយស្មោះត្រង់។

## គោលបំណង

- បង្កើតខ្សែអ៊ីសូលីនពីចំណុច ដោយ IDW និង Contour។
- ជ្រើសចន្លោះខ្សែ និងដាក់ស្លាកតម្លៃ។
- ផ្សំស្រមោលភ្នំ ពណ៌តាមកម្ពស់ និងខ្សែវណ្ឌ ដោយប្រើ Blending mode។
- សម្គាល់តំបន់ដែលការប៉ាន់ស្មានមិនច្បាស់។

## សកម្មភាពទី១៖ បង្កើតចំណុចវាស់គំរូ · ១៥ នាទី

1. **Processing → Vector creation → Random points in extent**៖ វិសាលភាពខេត្តកំពង់ឆ្នាំង · ចំនួន `12` · ចម្ងាយអប្បបរមា `8000` → `stations`
2. បន្ថែមវាល `rain` (Integer) ហើយបំពេញតម្លៃគំរូចន្លោះ ១ ២០០ ដល់ ២ ០០០ មម (វាយដោយដៃ ឬប្រើ `1200 + rand(0, 800)`)។
3. ដាក់ស្លាកតម្លៃលើចំណុច។

!!! note "ទិន្នន័យគំរូ"
    តម្លៃទាំងនេះជាតម្លៃគំរូសម្រាប់លំហាត់។ សម្រាប់ការងារពិត ប្រើទិន្នន័យស្ថានីយ៍ពីក្រសួងធនធានទឹក ឬទិន្នន័យអាកាសធាតុបើកចំហ។

## សកម្មភាពទី២៖ IDW និងខ្សែអ៊ីសូលីន · ២៥ នាទី

1. **Processing → Interpolation → IDW interpolation**៖ Vector layer `stations` · Attribute `rain` · Distance coefficient `2` · Extent ខេត្ត · Pixel size `250` → `rain_idw.tif`
2. **Raster → Extraction → Contour**៖ Interval `100` · Attribute `rain` → `isohyets.gpkg`
3. ដាក់ស្លាកលើខ្សែពីវាល `rain` ជាមួយ **Placement → Curved** និង Buffer ពណ៌ស។
4. ធ្វើឲ្យខ្សែរៀងរាល់ ២០០ មម ក្រាស់ជាង (Rule-based៖ `"rain" % 200 = 0`)។

## សកម្មភាពទី៣៖ បង្ហាញភាពមិនច្បាស់ · ២០ នាទី

1. **Buffer** លើ `stations` ចម្ងាយ `25000` → Dissolve → `covered`
2. **Difference**៖ ខេត្ត ដក `covered` → `uncertain`
3. ដាក់ `uncertain` ជាពណ៌សភាពថ្លា ៥០% នៅលើផែនទី ហើយដាក់ស្លាក «ទិន្នន័យតិច»។

**សំណួរ៖** ភាគរយប៉ុន្មាននៃខេត្ត ស្ថិតក្នុងចម្ងាយ ២៥ គម ពីស្ថានីយ៍?

## សកម្មភាពទី៤៖ ផែនទីរលកដីផ្សំ · ២៥ នាទី

1. បន្ថែម `dem_sample_synthetic.tif` ពីរដង (ស្រទាប់ពីរ)។
2. ស្រទាប់ក្រោម៖ **Hillshade** (Raster → Analysis → Hillshade · Azimuth `315` · Altitude `45`)។
3. ស្រទាប់លើ៖ **Singleband pseudocolor** ជាមួយពណ៌តាមកម្ពស់ (បៃតង → លឿង → ត្នោត) · **Blending mode = Multiply** ឬ Opacity ៦០%។
4. បន្ថែមខ្សែវណ្ឌ ១០០ ម មានស្លាក ([លំហាត់ទី៥](lab-05.md))។
5. សាកល្បង Azimuth `135` ហើយសង្កេតការបញ្ច្រាសរលកដី។

## សកម្មភាពទី៥៖ ប្លង់ · ១៥ នាទី

ធ្វើប្លង់ A4 ដែលមានផែនទីអ៊ីសូលីន និងផែនទីរលកដីជាប់គ្នា ព្រមទាំងកំណត់សម្គាល់អំពីវិធីអាំងទែប៉ូឡាស្យុង ចំនួនស្ថានីយ៍ និងកម្ពស់សំយោគ។

## លទ្ធផលត្រូវប្រគល់

- `stations` `rain_idw.tif` និង `isohyets.gpkg`។
- ស្រទាប់ `uncertain` និងភាគរយគ្របដណ្ដប់។
- ប្លង់ A4 ជាមួយកំណត់សម្គាល់។

## ជម្រើសអនុវត្តជាមួយទិន្នន័យក្នុង ZIP
