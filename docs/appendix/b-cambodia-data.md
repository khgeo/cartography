# ឧបសម្ព័ន្ធ ខ៖ ទិន្នន័យកម្ពុជា

សៀវភៅទាំងពីរ **ផែនទីវិទ្យា** និង **មូលដ្ឋានគ្រឹះនៃ GIS** ប្រើសំណុំទិន្នន័យ `Cambodia` តែមួយ (៤៣ ស្រទាប់ · EPSG:32648 · UTF-8)។ និស្សិតទាញយកម្ដង ហើយប្រើបានពេញពីរឆមាស។

!!! note "របៀបទាញយក"
    [:material-download: ទាញយក Cambodia.zip](https://github.com/khgeo/gis-fundamentals/releases/latest/download/Cambodia.zip){ .md-button .md-button--primary }

    ពន្លាឯកសារទៅក្នុងថតដែលផ្លូវ **គ្មានដកឃ្លា និងគ្មានអក្សរខ្មែរ** ឧទាហរណ៍ `D:\GIS\Cambodia`។

បញ្ជីស្រទាប់លម្អិត វាល លេខកូដរដ្ឋបាល ប្រភព និងចំណុចត្រូវប្រុងប្រយ័ត្ន មាននៅក្នុង [ឧបសម្ព័ន្ធ ខ នៃសៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/appendix/b-cambodia-data/)។
