# មគ្គុទ្ទេសក៍វាលទី១៖ សន្លឹកផែនទី និងការប្រើផែនទី

មគ្គុទ្ទេសក៍នេះពង្រីកខ្លឹមសារពីមេរៀនទី៤–៥ ទៅការងារជាក់ស្តែង៖ ជ្រើសផែនទីឱ្យត្រូវ បកស្រាយគែមសន្លឹក ស្វែងរកសន្លឹកជាប់គ្នា វាស់ផ្លូវ និងកត់លទ្ធផលដែលអាចពិនិត្យឡើងវិញបាន។

## ១. ជ្រើស «ផែនទីត្រឹមត្រូវ» មុនអានផែនទី

ផែនទីមួយអាចមានព័ត៌មានត្រឹមត្រូវ ប៉ុន្តែមិនសមនឹងភារកិច្ច។ សួរប្រាំចំណុច៖

| សំណួរ | ឧទាហរណ៍នៅកម្ពុជា | ផលវិបាកបើមិនពិនិត្យ |
|---|---|---|
| គោលបំណងអ្វី? | ស្វែងរកផ្លូវទៅភូមិ ឬប្រៀបធៀបប្រជាជនតាមឃុំ | ជ្រើសផែនទីប្រធានបទខុស |
| តំបន់ និងវិសាលភាពណា? | មួយស្រុក ឬទាំងប្រទេស | សន្លឹកមិនគ្របដណ្ដប់ |
| ត្រូវការលម្អិតប៉ុណ្ណា? | ផ្លូវលំ និងអូរ ត្រូវការមាត្រដ្ឋានធំ | ព័ត៌មានត្រូវបានធ្វើឱ្យទូទៅខ្លាំង |
| ទិន្នន័យឆ្នាំណា? | ផ្លូវថ្មី អាងទឹកថ្មី ព្រំឃុំថ្មី | សម្រេចចិត្តលើទិន្នន័យចាស់ |
| CRS/Datum អ្វី? | WGS 84 / UTM zone 48N | GPS និងផែនទីមិនត្រូវគ្នា |

## ២. អានគែមសន្លឹកដូចជា «អត្តសញ្ញាណបណ្ណផែនទី»

មុនមើលមាតិកាកណ្ដាល សរសេរចម្លើយក្នុងសៀវភៅវាល៖ ឈ្មោះ/លេខសន្លឹក មាត្រដ្ឋាន ចន្លោះខ្សែវណ្ឌ Datum ចំណោល ឆ្នាំប្រមូលទិន្នន័យ ឆ្នាំបោះពុម្ព អង្គភាពផលិត និងសន្លឹកជាប់គ្នា។ **ឆ្នាំបោះពុម្ពមិនតែងតែជាឆ្នាំទិន្នន័យទេ**។

### លេខសន្លឹក និងផែនទីសន្ទស្សន៍

ស៊េរីផែនទីបែងចែកតំបន់ធំជាសន្លឹក។ ផែនទីសន្ទស្សន៍ (index map) ប្រាប់លេខសន្លឹក និងទីតាំងជាប់គ្នា។ នៅពេលផ្លូវឆ្លងចេញពីគែម សូមកត់លេខសន្លឹកបន្ទាប់មុនចុះវាល។ កុំទាយតាមឈ្មោះកន្លែង ព្រោះឈ្មោះដូចគ្នាអាចកើតឡើងច្រើនទី។

## ៣. នីតិវិធីអានទីតាំង និងវាស់ផ្លូវ

1. បង្វិលផែនទីឱ្យទិសផែនទីស្របនឹងទិសដី ដោយយោងវត្ថុច្បាស់ពីរ ឬត្រីវិស័យ។
2. កំណត់ចំណុចចាប់ផ្ដើមដោយយោងផ្លូវប្រសព្វ ស្ទឹង ស្ពាន ឬកំពូលភ្នំ។
3. អានកូអរដោនេ **Easting មុន Northing** ហើយកត់ zone និង datum ជាមួយលេខ។
4. វាស់ផ្លូវកោងជាចម្រៀកខ្លីៗ បូកចម្ងាយផែនទី រួចបម្លែងតាមមាត្រដ្ឋាន។
5. បន្ថែមកត្តាជម្រាល ស្ថានភាពផ្លូវ និងពេលសម្រាក; ចម្ងាយត្រង់មិនស្មើចម្ងាយធ្វើដំណើរ។

!!! example "ឧទាហរណ៍គណនា"
    ផ្លូវលើផែនទី ១:៥០ ០០០ មានប្រវែង ៨.៤ សម។ ចម្ងាយដី = ៨.៤ × ៥០ ០០០ សម = ៤.២ គម។ ប្រសិនបើល្បឿនជាមធ្យម ៣ គម/ម៉ោង ពេលមូលដ្ឋាន = ១ ម៉ោង ២៤ នាទី។ បន្ថែមពេលឆ្លងស្ទឹង និងជម្រាលដោយឡែក។

## ៤. ប្រៀបធៀបការអនុវត្តល្អ និងខ្សោយ

| ខ្សោយ | ល្អ |
|---|---|
| កត់តែ `E=512345, N=1287654` | កត់ `WGS84 / UTM 48N, E 512345 m, N 1287654 m` |
| វាស់បន្ទាត់ត្រង់លើផ្លូវកោង | បំបែកជាចម្រៀកតាមកំណោង |
| ប្រើរូបថតអេក្រង់គ្មានប្រភព | កត់អ្នកផលិត ឆ្នាំ និងកាលបរិច្ឆេទទាញយក |
| គិតថាផែនទីចាស់ «ខុសទាំងអស់» | បែងចែកធាតុស្ថិរភាព និងធាតុផ្លាស់ប្តូរ |

## ៥. Mini challenge: រៀបចំដំណើរទៅសាលារៀនជនបទ

ជាក្រុម សម្គាល់ផ្លូវពីទីរួមស្រុកទៅសាលារៀនមួយ។ ផលិតកាតផ្លូវ ១ សន្លឹកដែលមាន៖ ចំណុចចាប់ផ្ដើម/បញ្ចប់ កូអរដោនេ ចម្ងាយ ប៉ាន់ស្មានពេល ឧបសគ្គពីរ ផ្លូវបម្រុង និងព័ត៌មានគែមផែនទី។ ក្រុមផ្សេងត្រូវអាចធ្វើតាមកាតដោយមិនសួរបន្ថែម។

??? question "ពិនិត្យចំណេះដឹង"
    1. ហេតុអ្វីត្រូវកត់ Datum និង zone ជាមួយកូអរដោនេ?  
    2. ផែនទី ១:២៥ ០០០ និង ១:១០០ ០០០ មួយណាលម្អិតជាង?  
    3. ប្រវែង ៦ សម លើផែនទី ១:៥០ ០០០ ស្មើប៉ុន្មានគីឡូម៉ែត្រ?  
    **ចម្លើយ៖** (១) ដើម្បីបកស្រាយលេខក្នុងប្រព័ន្ធត្រឹមត្រូវ (២) ១:២៥ ០០០ (៣) ៣ គម។

## ៦. ភ្ជាប់ទៅ QGIS

បង្កើត project CRS ឱ្យត្រូវនឹងសន្លឹក បន្ថែមរូបសន្លឹកដែលបាន georeference ហើយគូសផ្លូវជាស្រទាប់បន្ទាត់។ ប្រើ **Measure Line** ពិនិត្យការគណនាដោយដៃ និងបំពេញវាល `source`, `map_year`, `checked_on`, `confidence`។
