# មេរៀនទី១៤៖ ប្លង់ផែនទី និងឋានានុក្រមមើលឃើញ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១៤ ក្នុងចំណោម ១៥

ផែនទីល្អអាចខូចដោយប្លង់មិនល្អ។ **ប្លង់ផែនទី (Map layout)** គឺជាការរៀបចំធាតុទាំងអស់លើទំព័រ៖ ចំណងជើង តួផែនទី សញ្ញាសម្គាល់ផែនទី មាត្រដ្ឋាន ប្រភព និងផែនទីទីតាំង។

មេរៀននេះពន្យល់ក្បួនប្លង់ ការបង្កើតឋានានុក្រម ការជ្រើសទំហំ និងទិសក្រដាស និងការត្រៀមបោះពុម្ព ឬចេញផ្សាយអនឡាញ។

## ១៤.១. គោលបំណងសិក្សា

2. អនុវត្តក្បួនប្លង់៖ ទំហំ ឋានានុក្រម តម្រឹម ចន្លោះ តុល្យភាព និងភាពសាមញ្ញ។
3. ជ្រើសទំហំ និងទិសក្រដាសតាមរូបរាងតំបន់សិក្សា។
4. រៀបចំប្លង់ក្នុង QGIS Print Layout និងនាំចេញត្រឹមត្រូវ។
5. វាយតម្លៃប្លង់ដោយប្រើបញ្ជីត្រួតពិនិត្យ។

## ១៤.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីល្អ ប្លង់មិនល្អ

ក្រុមពីរធ្វើផែនទីដង់ស៊ីតេប្រជាជនដូចគ្នា ដោយប្រើទិន្នន័យ ថ្នាក់ និងពណ៌ដូចគ្នា។

- ក្រុមទី១៖ ផែនទីកាន់កាប់ ៦០% នៃទំព័រ ធាតុតម្រឹមគ្នា ចន្លោះស្មើ។
- ក្រុមទី២៖ ផែនទីតូចនៅជ្រុងខាងលើឆ្វេង ធាតុប្រាំពីរដាក់ខ្ចាត់ខ្ចាយ អត្ថបទវែងនៅខាងក្រោម។

អ្នកអានទាំងអស់ចូលចិត្តផែនទីក្រុមទី១ ទោះមិនអាចពន្យល់ថាហេតុអ្វី។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- ក្បួនណាដែលធ្វើឲ្យប្លង់មួយមើលទៅរៀបរយ?
- តើផែនទីគួរធំប៉ុណ្ណា ធៀបនឹងធាតុផ្សេង?
- តើត្រូវជ្រើសទំហំ និងទិសក្រដាសយ៉ាងណា?

### ១៤.៣.២. ក្បួនប្លង់ប្រាំមួយ

1. **ទំហំ**៖ ផែនទីជាធាតុសំខាន់បំផុត គួរកាន់កាប់ ៥០ ដល់ ៧០% នៃផ្ទៃ។
2. **ឋានានុក្រម**៖ ចំណងជើង → ផែនទី → សញ្ញាសម្គាល់ផែនទី → ធាតុបន្ទាប់បន្សំ → ប្រភព។
3. **តម្រឹម (Alignment)**៖ ធាតុតម្រឹមតាមក្រឡាដូចគ្នា។ គែមឆ្វេងរបស់ចំណងជើង សញ្ញាសម្គាល់ផែនទី និងប្រភព គួរស្ថិតលើខ្សែតែមួយ។
4. **ចន្លោះ (Spacing)**៖ ចន្លោះទំនេរស្មើគ្នា · គែមក្រដាសយ៉ាងតិច ១០ មម · ចន្លោះទំនេរមិនមែនជាកន្លែងខាតបង់។
5. **តុល្យភាព (Balance)**៖ ទម្ងន់មើលឃើញចែកស្មើ។ ធាតុធំ ឬដិត ទាញភ្នែកច្រើន។
6. **ភាពសាមញ្ញ**៖ ធាតុនីមួយៗត្រូវមានហេតុផល។ ពេលសង្ស័យ លុបចេញ។

| កម្ពុជាទាំងមូល (ទទឹង ៥៧៣ គម × កម្ពស់ ៤៨១ គម) | **ផ្ដេក (Landscape)** ឬការ៉េ |
| ខេត្តវែងបញ្ឈរ (ឧ. រតនគិរី–ស្ទឹងត្រែង) | **បញ្ឈរ (Portrait)** |

### ១៤.៣.៥. បញ្ជីត្រួតពិនិត្យប្លង់

មុនបញ្ចប់ផែនទី ត្រួតពិនិត្យ៖

1. ចំណងជើងប្រាប់ **អ្វី កន្លែងណា ពេលណា**។
2. សញ្ញាសម្គាល់ផែនទីពន្យល់និមិត្តសញ្ញាទាំងអស់ រួមទាំង «គ្មានទិន្នន័យ»។
3. របារមាត្រដ្ឋានមានលេខមូល និងឯកតា។
4. ប្រភព ឆ្នាំទិន្នន័យ CRS អ្នកផលិត និងថ្ងៃ។
5. ធាតុតម្រឹម និងចន្លោះស្មើ។
6. អក្សរអានបាននៅទំហំពិត (បោះពុម្ពគំរូ)។
7. ពណ៌អានបានពេលសខ្មៅ និងសម្រាប់អ្នកខ្វះពណ៌ ([មេរៀនទី៨](lesson-08.md))។
8. គ្មានធាតុណាដែលអ្នកមិនអាចពន្យល់ហេតុផល។

## ១៤.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ប្លង់ A4 សម្រាប់ផែនទីដង់ស៊ីតេ

ផែនទីដង់ស៊ីតេប្រជាជនកម្ពុជា ២០១៧ សម្រាប់របាយការណ៍ A4។

### ជំហានទី១៖ ជ្រើសទិស

កម្ពុជាទទឹង ៥៧៣ គម និងកម្ពស់ ៤៨១ គម ពោលគឺស្ទើរការ៉េ។ A4 បញ្ឈរផ្ដល់កន្លែងសម្រាប់សញ្ញាសម្គាល់ផែនទី និងប្រភពនៅខាងក្រោម ដូច្នេះជ្រើស **បញ្ឈរ**។

### ជំហានទី២៖ កំណត់ផ្ទៃផែនទី

ផែនទីកាន់កាប់ ១៨០ × ១៦០ មម ប្រហែល ៥៥% នៃផ្ទៃ A4 (២១០ × ២៩៧ មម) ដែលនៅសល់សម្រាប់ចំណងជើង និងធាតុអម។

### ជំហានទី៣៖ រៀបចំធាតុ
