## ស្ថានភាព

មន្ទីរអប់រំ និងមន្ទីរសាធារណការសុំផែនទីតែមួយ ដែលបង្ហាញ៖ **ប្រភេទសាលារៀន** (ប្រភេទ) **ចំនួនប្រជាជនភូមិ** (បរិមាណ) និង **ថ្នាក់ផ្លូវ** (លំដាប់)។ ទិន្នន័យបីប្រភេទ ត្រូវការអថេរមើលឃើញបីផ្សេងគ្នា។

## គោលបំណង

- ប្រើ Categorized Graduated និង Data-defined override ក្នុង QGIS។
- ផ្គូផ្គងអថេរមើលឃើញជាមួយប្រភេទទិន្នន័យ។
- បង្កើតសញ្ញាសមាមាត្រដែលធ្វើមាត្រដ្ឋានតាមផ្ទៃ។
- បង្កើតឋានានុក្រមមើលឃើញ និងសញ្ញាសម្គាល់ផែនទីច្បាស់។

## សកម្មភាពទី១៖ រៀបចំតំបន់សិក្សា · ១០ នាទី

1. **Extract by expression** លើ `Kh_Province_Boundary`៖ `"ProvGis" = 'KH04'` → `kc_province`
2. **Extract by location**៖ `Kh_School` within `kc_province` → `kc_schools` · `Census_Village` ដោយ `left("VILL_CODE",2) = '04'` → `kc_villages`
3. **Clip** `Kh_Main_Roads_MPWT2014` ជាមួយ `kc_province` → `kc_roads`

## សកម្មភាពទី២៖ ប្រភេទ → រាង និងពណ៌ · ២០ នាទី

1. `kc_schools` → **Symbology → Categorized** លើ `SCHOOL_TYP` → Classify។
2. សម្រាប់ថ្នាក់នីមួយៗ ជ្រើស **រាង** ខុសគ្នា (Simple Marker៖ circle · square · triangle · star) ហើយរក្សា **ពណ៌តែមួយ**។
3. ធ្វើម្ដងទៀតដោយប្រើ **ពណ៌** ខុសគ្នា និងរាងតែមួយ។ ប្រៀបធៀបផែនទីទាំងពីរ។

**សំណួរ៖** ផែនទីមួយណាងាយអានជាង ពេលសញ្ញាតូច? ផែនទីមួយណាងាយអានជាង ពេលបោះពុម្ពសខ្មៅ?

## សកម្មភាពទី៣៖ បរិមាណ → ទំហំសមាមាត្រ · ២៥ នាទី

1. `kc_villages` → Symbology → **Single Symbol** → ចុចរូបកណ្ដុរនៅជាប់ **Size** → **Edit** (Data-defined override) → Expression៖

    ```text
    0.09 * sqrt("TOTPOP")
    ```

    ឯកតា Size ជា **Millimeters**។ ភូមិ ១ ០០០ នាក់ → ២,៨ មម · ៤ ០០០ នាក់ → ៥,៧ មម។

2. ធ្វើម្ដងទៀតដោយកន្សោមខុស `0.0012 * "TOTPOP"` (ធ្វើមាត្រដ្ឋានតាមកាំ) ហើយប្រៀបធៀបជាមួយឫសការ៉េ។
3. កំណត់ **Opacity** ៧០% និងព្រំសញ្ញាពណ៌ស ដើម្បីកុំឲ្យសញ្ញាត្រួតគ្នាបាត់។
4. បន្ថែមសញ្ញាសម្គាល់ផែនទីសម្រាប់សញ្ញាសមាមាត្រ៖ Layer Properties → Legend → **Data-defined size legend** → Separated legend items ជាមួយតម្លៃ ១ ០០០ · ៣ ០០០ · ៦ ០០០។

**សំណួរ៖** កន្សោមមួយណាធ្វើឲ្យភូមិធំមើលទៅធំហួសហេតុ? ហេតុអ្វី?

## សកម្មភាពទី៤៖ លំដាប់ → ទទឹង និងតម្លៃពន្លឺ · ២០ នាទី

1. `kc_roads` → **Categorized** លើ `type_en`៖ ផ្លូវជាតិចម្បង ទទឹង ១,២ មម · ផ្លូវជាតិបន្ទាប់បន្សំ ០,៦ មម ពណ៌ដូចគ្នា។
2. បន្ថែម **Scale-dependent visibility**៖ បង្ហាញ `kc_villages` តែនៅមាត្រដ្ឋានធំជាង ១ : ៥០០ ០០០។
3. រៀបចំឋានានុក្រម៖ ឃុំ (ព្រំស្ដើងប្រផេះ) → ផ្លូវ → ភូមិ → សាលា។ ពិនិត្យលំដាប់ស្រទាប់។

## សកម្មភាពទី៥៖ ផែនទី និងការសាកល្បង · ១៥ នាទី

1. Print Layout A4៖ ចំណងជើង · សញ្ញាសម្គាល់ផែនទី (រៀបចំឈ្មោះថ្នាក់ជាភាសាខ្មែរ) · របារមាត្រដ្ឋាន · ប្រភព។
2. នាំចេញ PDF ហើយបោះពុម្ព ឬមើលទំហំពិត ១០០%។
3. **តេស្ត ៣ វិនាទី**៖ បង្ហាញផែនទីដល់មិត្តម្នាក់ ៣ វិនាទី ហើយសួរថាគាត់ចាំអ្វីមុនគេ។ កត់ត្រាចម្លើយ ហើយកែឋានានុក្រមបើចាំបាច់។
