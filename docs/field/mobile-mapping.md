# មគ្គុទ្ទេសក៍វាលទី៣៖ Avenza Maps និងផែនទីចល័ត Offline

កម្មវិធីផែនទីចល័តអាចបង្ហាញទីតាំងលើ PDF/GeoPDF ដែលមាន georeference ទោះគ្មានអ៊ីនធឺណិត។ ឈ្មោះប៊ូតុងអាចផ្លាស់ប្តូរតាមកំណែកម្មវិធី ប៉ុន្តែលំហូរការងារស្នូលនៅដដែល៖ **នាំផែនទីចូល → ផ្ទៀងផ្ទាត់ទីតាំង → សម្គាល់/តាមដាន → ពិពណ៌នា → export → QC**។

## ១. រៀបចំផែនទីមុនចេញ

- ប្រើ GeoPDF/GeoTIFF ដែលមាន CRS និង extent ត្រឹមត្រូវ។ រូប PDF ធម្មតាមិនដឹងទីតាំងដោយខ្លួនឯងទេ។
- បើកផែនទីនៅកន្លែងដែលមានអ៊ីនធឺណិត បន្ទាប់មកសាក **airplane mode** ដើម្បីបញ្ជាក់ថាវាដំណើរការ offline។
- ពិនិត្យថាចំណុចសាកល្បងពីរឬបីស្ថិតនៅទីតាំងដែលស្គាល់។
- កត់ឈ្មោះផែនទី កំណែ កាលបរិច្ឆេទ និង CRS។

## ២. លំហាត់ប្រាំមួយជំហាន

1. Find your current location និងបញ្ជាក់ថាអ្នកស្ថិតក្នុង extent ផែនទី។
2. ពិនិត្យ coordinate display និង datum។
3. Mark location ជាមួយ ID និង attribute មុនចាកចេញពីចំណុច។
4. Start tracking ពេលចាប់ផ្ដើមផ្លូវ ហើយ stop នៅចុងផ្លូវ; កុំទុកឱ្យ track រត់នៅពេលជិះទៅផ្ទះ។
5. Measure distance ហើយប្រៀបធៀបជាមួយប្រវែង track; ខុសគ្នា ព្រោះមួយជាបន្ទាត់គូស មួយជាផ្លូវបានធ្វើ។
6. Export ទៅ GPX/KML/CSV និងរក្សាច្បាប់ចម្លងដើម។

## ៣. កំហុសដែលអាចរកឃើញពីរូបរាង track

| រូបរាង | មូលហេតុអាចមាន | សកម្មភាព |
|---|---|---|
| បន្ទាត់លោតទៅឆ្ងាយ | fix ខ្សោយ ឬ track នៅបើកក្នុងយានយន្ត | កត់ anomaly; កុំលុប raw file |
| ចំណុចកកុញពេលឈប់ | interval តាមពេល និងឧបករណ៍កំពុងស្ងៀម | កំណត់ filter ក្នុង working copy |
| ខ្វះចន្លោះ | battery/app pause/ដំបូលបិទសញ្ញា | កត់ចំណាំ និងពិនិត្យសៀវភៅវាល |
| ផែនទីទាំងមូលផ្លាស់ | CRS/datum ឬ georeference ខុស | ឈប់ប្រមូល និងដោះស្រាយប្រព័ន្ធយោង |

## ៤. សកម្មភាពក្រុមនៅបរិវេណសាកលវិទ្យាល័យ

ក្រុម ៣ នាក់៖ អ្នកកាន់ទូរស័ព្ទ អ្នកកត់ត្រា និងអ្នក QC។ ប្រមូលអគារ ៥ ចំណុច ផ្លូវថ្មើរជើងមួយ track និងវាស់ចម្ងាយរវាងអគារពីរ។ ប្តូរតួនាទីនៅពាក់កណ្ដាល។ ផលិតតារាងមាន ID, coordinates, accuracy, time, description, photo ID និងភាពជឿជាក់។

## ៥. QGIS handoff

នាំចូល file, បម្លែងទៅ GeoPackage, កំណត់ layer CRS ត្រឹមត្រូវ និង Run **Check validity**។ បន្ថែម `qc_status` និង `qc_note`; កែតែ working layer។ រចនាផែនទីដែលបង្ហាញ track, waypoint និងតំបន់ដែល coverage ខ្វះ។
