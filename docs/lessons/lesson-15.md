# មេរៀនទី១៥៖ ការធ្វើឲ្យទូទៅ សីលធម៌ផែនទី និងការចេញផ្សាយ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ១៥ ក្នុងចំណោម ១៥

មេរៀនចុងក្រោយនេះភ្ជាប់គ្រប់អ្វីៗចូលគ្នា។ វានិយាយអំពី **ការធ្វើឲ្យទូទៅ** ដែលជាការសម្រេចចិត្តថាអ្វីត្រូវបង្ហាញនៅមាត្រដ្ឋាននីមួយៗ **សីលធម៌ផែនទី** ដែលជាការទទួលខុសត្រូវចំពោះអ្នកអាន និង **ការចេញផ្សាយ** ទាំងបោះពុម្ព និងអនឡាញ។

មេរៀននេះក៏ណែនាំ **គម្រោងបញ្ចប់វគ្គ** ផងដែរ។

## ១៥.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់ប្រតិបត្តិការធ្វើឲ្យទូទៅ និងទំនាក់ទំនងជាមួយមាត្រដ្ឋាន។
2. កំណត់វិធីដែលផែនទីអាចបំភាន់ ទោះទិន្នន័យត្រឹមត្រូវ។
3. អនុវត្តបញ្ជីត្រួតពិនិត្យសីលធម៌ មុនចេញផ្សាយ។
4. ជ្រើសទម្រង់ចេញផ្សាយ និងកំណត់អាជ្ញាបណ្ណ ព្រមទាំងការដកស្រង់ប្រភព។
5. រៀបចំសំណើគម្រោងបញ្ចប់វគ្គ។

### ចំណេះដឹងមុនត្រូវមាន

- ខ្លឹមសារមេរៀនទី១ ដល់ទី១៤។

## ១៥.២. ស្ថានភាពបើកមេរៀន៖ ផែនទីដដែល រឿងផ្ទុយគ្នា

មុនបោះឆ្នោតក្នុងតំបន់មួយ ក្រុមពីរបោះពុម្ពផែនទី «ការទទួលបានទឹកស្អាត» ដោយប្រើទិន្នន័យជំរឿនតែមួយ។

- ក្រុមទី១ ប្រើព្រំថ្នាក់ ៤០ · ៦០ · ៨០% ហើយពណ៌ក្រហមចាប់ពី ៨០% ចុះក្រោម។ ផែនទីមើលទៅក្រហមស្ទើរទាំងស្រុង៖ «វិបត្តិទឹក»។
- ក្រុមទី២ ប្រើព្រំ ២០ · ៤០ · ៦០% ហើយពណ៌បៃតងចាប់ពី ៦០% ឡើងទៅ។ ផែនទីមើលទៅបៃតងស្ទើរទាំងស្រុង៖ «ការអភិវឌ្ឍជោគជ័យ»។

លេខមិនត្រូវបានកែទេ។ ការសម្រេចចិត្តផែនទីវិទ្យាទើបធ្វើឲ្យរឿងផ្ទុយគ្នា។

សំណួរដែលមេរៀននេះឆ្លើយ៖

- ការសម្រេចចិត្តណាខ្លះដែលអាចបំភាន់អ្នកអាន?
- តើអ្វីជាបន្ទាត់រវាងការរចនា និងការបំភាន់?
- តើត្រូវប្រាប់អ្វីខ្លះពេលចេញផ្សាយ?

### ១៥.៣.១. ការធ្វើឲ្យទូទៅ

**ការធ្វើឲ្យទូទៅ (Generalisation)** គឺជាការកែទិន្នន័យឲ្យសមនឹងមាត្រដ្ឋាន និងគោលបំណង។ វាមិនមែនជាការបាត់បង់គុណភាពទេ បើធ្វើដោយមានក្បួន។

**ក្បួន Radical Law (Töpfer)** ប្រាប់ថាចំនួនវត្ថុដែលគួររក្សា ថយតាមឫសការ៉េនៃសមាមាត្រមាត្រដ្ឋាន។ ឧទាហរណ៍ ពេលប្ដូរពី ១:៥០ ០០០ ទៅ ១:២០០ ០០០ (តូចជាង ៤ ដង) ចំនួនវត្ថុគួរថយប្រហែលពាក់កណ្ដាល។

!!! warning "ការធ្វើឲ្យទូទៅ និងភាពត្រឹមត្រូវ"

### ១៥.៣.៣. បញ្ជីត្រួតពិនិត្យសីលធម៌

មុនចេញផ្សាយ សួរ៖

1. តើសារនៃផែនទី ត្រូវនឹងអ្វីដែលទិន្នន័យបង្ហាញឬទេ?
2. តើខ្ញុំបានប្រាប់វិធីចាត់ថ្នាក់ ប្រភព ឆ្នាំ និង CRS ឬទេ?
3. តើខ្ញុំបានធ្វើឲ្យស្តង់ដារ (អត្រា ដង់ស៊ីតេ) ពេលចាំបាច់ឬទេ?
4. តើផែនទីបង្ហាញភាពមិនច្បាស់ និងទិន្នន័យខ្វះខាតឬទេ?
5. តើខ្ញុំបានពិចារណាថាអ្នកណាទទួលផលប្រយោជន៍ និងអ្នកណាអាចរងគ្រោះឬទេ?
6. តើផែនទីនេះប៉ះពាល់ឯកជនភាព ឬសុវត្ថិភាពមនុស្សឬទេ?
7. តើអ្នកអានដែលមិនស្គាល់តំបន់ អាចយល់ខុសយ៉ាងណា?

**ឯកជនភាព**៖ ទិន្នន័យអំពីបុគ្គល (អ្នកជំងឺ គ្រួសារក្រីក្រ) មិនគួរធ្វើផែនទីជាចំណុចទេ។ ត្រូវសរុបតាមឃុំ ឬធ្វើឲ្យទីតាំងព្រិល។ ចំណុចមួយលើផែនទី អាចជាផ្ទះជាក់លាក់មួយ។

## ១៥.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ពិនិត្យផែនទីទឹកស្អាតឡើងវិញ

យើងវិភាគផែនទីទាំងពីរក្នុងស្ថានភាពបើកមេរៀន ដោយប្រើបញ្ជីត្រួតពិនិត្យសីលធម៌។

### ជំហានទី១៖ ពិនិត្យទិន្នន័យ

ទិន្នន័យដូចគ្នា៖ ភាគរយគ្រួសារដែលមានទឹកស្អាត។ គ្មានការកែលេខទេ។

### ជំហានទី២៖ ពិនិត្យព្រំថ្នាក់

ក្រុមទី១ ប្រើព្រំដែលដាក់ ៧៩% ក្នុងថ្នាក់ «ទាប» ឯក្រុមទី២ ដាក់ ៦១% ក្នុងថ្នាក់ «ខ្ពស់»។ ទាំងពីរជាជម្រើសដែលអាចការពារបាន ប៉ុន្តែគ្មានក្រុមណាប្រាប់វិធីចាត់ថ្នាក់ទេ។

### ជំហានទី៣៖ ពិនិត្យពណ៌

ក្រហម និងបៃតងផ្ទុកអត្ថន័យ «អាក្រក់» និង «ល្អ» ដែលពង្រឹងរឿងរបស់ក្រុមនីមួយៗ។ ឈុតតគ្នាអព្យាក្រឹតជាង។

### ជំហានទី៤៖ ការកែដែលស្មោះត្រង់

ប្រើព្រំមូល (២៥ · ៥០ · ៧៥%) · ឈុតតគ្នាពណ៌តែមួយ · បន្ថែមក្រាបចែកចាយតូច · សរសេរវិធីចាត់ថ្នាក់ ប្រភព និងឆ្នាំ · បន្ថែមចំណាំអំពីឃុំដែលមានគ្រួសារតិច។

### ជំហានទី៥៖ ការសម្រេចចិត្តចុងក្រោយ

បង្ហាញផែនទីតែមួយ ជាមួយតារាងតម្លៃ ឬក្រាប ដើម្បីឲ្យអ្នកអានពិនិត្យលេខដោយខ្លួនឯង។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ផែនទីទាំងពីរប្រើទិន្នន័យត្រឹមត្រូវ ប៉ុន្តែការជ្រើសព្រំថ្នាក់ និងពណ៌បង្កើតសារផ្ទុយគ្នា។ ការប្រាប់វិធីចាត់ថ្នាក់ ការប្រើព្រំមូល និងឈុតតគ្នាអព្យាក្រឹត ធ្វើឲ្យផែនទីស្មោះត្រង់ជាង។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    យើងមិនអាចនិយាយថាក្រុមណាមួយបានកុហកទេ។ ការសម្រេចចិត្តទាំងពីរស្ថិតក្នុងវិសាលភាពនៃការអនុវត្តធម្មតា។ អ្វីដែលខ្វះគឺ **តម្លាភាព**៖ ការប្រាប់អ្នកអានពីវិធីសម្រេចចិត្ត។

## ១៥.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «ផែនទីដែលមានទិន្នន័យត្រឹមត្រូវ មិនអាចបំភាន់»**
ការសម្រេចចិត្តរចនាអាចប្ដូរសារ ដោយមិនកែលេខសោះ។

**២. «ការធ្វើឲ្យទូទៅ = ការធ្វើឲ្យទិន្នន័យអន់»**
វាជាការសម្របតាមមាត្រដ្ឋាន។ ការមិនធ្វើឲ្យទូទៅ ទើបធ្វើឲ្យផែនទីអានមិនបាន។

**៣. «ការដាក់ចំណុចទិន្នន័យបុគ្គល គ្មានបញ្ហា បើមិនដាក់ឈ្មោះ»**
ទីតាំងខ្លួនឯងអាចកំណត់អត្តសញ្ញាណបាន។ ត្រូវសរុប ឬធ្វើឲ្យព្រិល។

**៤. «ការដកស្រង់ប្រភពជាជម្រើស»**
វាជាតម្រូវការទាំងផ្នែកច្បាប់ និងវិទ្យាសាស្ត្រ។

**៥. «ផែនទីអនឡាញមិនចាំបាច់មានមេតាទិន្នន័យ»**
ផែនទីអនឡាញត្រូវការវាកាន់តែច្រើន ព្រោះវាត្រូវចែករំលែកឆាប់រហ័ស ដោយគ្មានបរិបទ។

សរសេរសំណើគម្រោងបញ្ចប់វគ្គ ១ ទំព័រ តាមគំរូក្នុង[លំហាត់ទី១៥](../workbook/lab-15.md)៖ សំណួរ · តំបន់ · ទិន្នន័យ និងប្រភព · ប្រភេទផែនទីដែលស្នើ · ការសម្រេចចិត្តផែនទីវិទ្យាសំខាន់ៗ · និងដែនកំណត់ដែលអ្នករំពឹង។

## កំណត់សម្គាល់សម្រាប់គ្រូបង្រៀន

### ក. ការបែងចែកពេលវេលា ១៨០ នាទី

| សកម្មភាព | ពេលវេលា |
|---|---:|
| ស្ថានភាពបើកមេរៀន៖ រឿងផ្ទុយគ្នា | ១៥ នាទី |
| ការធ្វើឲ្យទូទៅ និងពិសោធន៍ | ៣៥ នាទី |
| របៀបដែលផែនទីបំភាន់ | ៣០ នាទី |
| បញ្ជីត្រួតពិនិត្យសីលធម៌ និងឯកជនភាព | ២៥ នាទី |
| ការចេញផ្សាយ និងអាជ្ញាបណ្ណ | ២៥ នាទី |
| គម្រោងបញ្ចប់វគ្គ និងឧទាហរណ៍ | ៤៥ នាទី |
| សង្ខេបវគ្គសិក្សា | ៥ នាទី |
| **សរុប** | **១៨០ នាទី / ៣ ម៉ោង** |

### ខ. ការភ្ជាប់ទៅមេរៀនបន្ទាប់

នេះជាមេរៀនចុងក្រោយនៃ **ផែនទីវិទ្យា**។ ខ្សែស្រឡាយនៃវគ្គទាំងមូល៖ **ផែនដី និងកូអរដោនេ** (មេរៀនទី១–៥) → **ភាសាមើលឃើញ** (មេរៀនទី៦–៨) → **ផែនទីប្រធានបទ** (មេរៀនទី៩–១២) → **ការរចនា និងការទទួលខុសត្រូវ** (មេរៀនទី១៣–១៥)។
