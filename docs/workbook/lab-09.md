# លំហាត់ទី៩៖ ធ្វើផែនទី Choropleth ឲ្យស្មោះត្រង់

    **មេរៀនពាក់ព័ន្ធ៖** [មេរៀនទី៩៖ ផែនទី Choropleth និងការធ្វើឲ្យស្តង់ដារ](../lessons/lesson-09.md)

## ស្ថានភាព

មន្ទីរផែនការសុំផែនទីពីរ៖ ផែនទីដង់ស៊ីតេប្រជាជនតាមខេត្ត និងផែនទីអត្រាសេវាអប់រំ (សិស្សក្នុងមួយសាលា) តាមស្រុក។ អ្នកនឹងឃើញថាអ្នកភាគបែងខុសគ្នា ផ្ដល់ផែនទីខុសគ្នា។

## គោលបំណង

- គណនាតម្លៃស្តង់ដារពីចំនួនដុល។
- ធ្វើ Choropleth ត្រឹមត្រូវជាមួយថ្នាក់ ពណ៌ និងសញ្ញាសម្គាល់ផែនទី។
- ប្រៀបធៀបលទ្ធផលកម្រិតខេត្ត និងកម្រិតឃុំ (MAUP)។
- ដោះស្រាយតម្លៃ NULL និង «គ្មានទិន្នន័យ»។

## ឯកសារដែលប្រើ

ប្រើសំណុំទិន្នន័យ `Cambodia` ([ឧបសម្ព័ន្ធ ខ](../appendix/b-cambodia-data.md))។

| ស្រទាប់ | ថត | វាល |
|---|---|---|
| `Kh_Province_Boundary` | `Admin/` | `POP2017` `Area_Km2` |
| `Kh_District_area` · `Kh_Commune_area` | `Admin/` | `ProvGis` `DistGis` |
| `Census_Commune` | `Census_2008/` | `COMM_CODE` `TOTPOP` |
| `Kh_School` | `School/` | |

## សកម្មភាពទី១៖ ចំនួនដុល ធៀបនឹងដង់ស៊ីតេ · ២៥ នាទី

1. បន្ថែម `Kh_Province_Boundary`។ Field Calculator៖ `dens = "POP2017" / "Area_Km2"` (ឬ `$area / 1e6` សម្រាប់ផ្ទៃពិតពីធរណីមាត្រ)។
2. ធ្វើផែនទី Graduated លើ `POP2017` (Natural Breaks · ៥ ថ្នាក់ · Reds) ហើយថតរូបអេក្រង់។
3. ធ្វើម្ដងទៀតលើ `dens` ហើយថតរូបអេក្រង់។
4. បំពេញតារាង៖

    | | ខេត្តកំពូល ៣ | អ្វីដែលផែនទីនេះឆ្លើយ |
    |---|---|---|
    | ចំនួនដុល | | |
    | ដង់ស៊ីតេ | | |

**សំណួរ៖** ហេតុអ្វីផែនទីចំនួនដុលមើលទៅស្រដៀងផែនទីផ្ទៃខេត្ត?

## សកម្មភាពទី២៖ អត្រាសេវា · ២៥ នាទី

1. **Join attributes by location (summary)**៖ Input `Kh_District_area` · Join `Kh_School` · Predicate `contains` · Summary **count** → `districts_schools`
2. ភ្ជាប់ចំនួនប្រជាជនស្រុក (ពី `Census_Commune` ដោយសរុបតាម `DistGis` ឬប្រើ `Census_District` បើមាន)។
3. Field Calculator៖

    ```text
    "schools_count" / ("pop" / 10000)
    ```

    គឺចំនួនសាលាក្នុងប្រជាជន ១០ ០០០ នាក់។

4. ធ្វើ Choropleth លើតម្លៃនេះ។ ស្រុកណាមានសេវាខ្ពស់ជាងគេ? ស្រុកណាទាបជាងគេ?

!!! warning "ភាគបែងតូច"
    ស្រុកដែលមានប្រជាជនតិច ផ្ដល់អត្រាមិនស្ថិរ។ បន្ថែមចំណាំលើផែនទី ឬដកស្រុកដែលមានប្រជាជនតិចជាងកម្រិតជាក់លាក់។

## សកម្មភាពទី៣៖ MAUP · ២០ នាទី

1. ធ្វើផែនទីដង់ស៊ីតេឃុំសម្រាប់ខេត្តកំពង់ឆ្នាំង (ភ្ជាប់ `Census_Commune` ដូច[លំហាត់ទី៧](lab-07.md))។
2. ដាក់ផែនទីកម្រិតខេត្ត និងកម្រិតឃុំជាប់គ្នាក្នុងប្លង់តែមួយ ដោយប្រើ **ព្រំថ្នាក់ដូចគ្នា**។
3. សរសេរ ៣ ទៅ ៥ ប្រយោគ៖ អ្វីដែលកម្រិតខេត្តលាក់ ហើយសេចក្ដីសន្និដ្ឋានណាដែលមិនអាចធ្វើបាន។

## សកម្មភាពទី៤៖ គ្មានទិន្នន័យ និងការបញ្ចប់ · ២០ នាទី

1. ធ្វើឲ្យឃុំមួយមានតម្លៃ NULL (ឧទាហរណ៍ លុបតម្លៃមួយ) ហើយកំណត់ពណ៌ប្រផេះជាមួយស្លាក «គ្មានទិន្នន័យ» ក្នុងផ្ទាំង Graduated (ថ្នាក់ **all other values**)។
2. រៀបចំសញ្ញាសម្គាល់ផែនទី៖ ឯកតា ឆ្នាំ វិធីចាត់ថ្នាក់។
3. នាំចេញ PDF A4 ជាមួយចំណងជើងច្បាស់ ឧទាហរណ៍ «ដង់ស៊ីតេប្រជាជនតាមខេត្ត ឆ្នាំ ២០១៧ (នាក់/គម²)»។

## លទ្ធផលត្រូវប្រគល់

- ផែនទីចំនួនដុល និងផែនទីដង់ស៊ីតេ ព្រមទាំងតារាងប្រៀបធៀប។
- ផែនទីអត្រាសេវាតាមស្រុក។
- ប្លង់ប្រៀបធៀបខេត្ត/ឃុំ និងការពន្យល់ MAUP។
