# មេរៀនទី៥៖ ផែនទីទីសណ្ឋាន ខ្សែវណ្ឌ និងក្រឡាកូអរដោនេ

!!! info "ព័ត៌មានមេរៀន"
    **រយៈពេលបង្រៀនដែលស្នើ៖ ៣ ម៉ោង** · មេរៀនទី ៥ ក្នុងចំណោម ១៥

ផែនទីទីសណ្ឋាន (Topographic map) ជាផែនទីយោងទូទៅដ៏សំខាន់បំផុតមួយ។ វាបង្ហាញទាំងវត្ថុលើដី (ផ្លូវ ភូមិ ស្ទឹង) និង **រូបរាងនៃដី** តាមរយៈខ្សែវណ្ឌ។ វិស្វករ អ្នករៀបចំផែនការ កងទ័ព និងអ្នកជួយសង្គ្រោះ សុទ្ធតែប្រើវា។

មេរៀននេះបង្រៀនការអានខ្សែវណ្ឌ ការគណនាជម្រាល ការគូសផ្នែកកាត់បញ្ឈរ និងការអានលេខយោងក្រឡាកូអរដោនេ។

---

## ៥.១. គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀន និស្សិតអាច៖

1. ពន្យល់ខ្សែវណ្ឌ ចន្លោះខ្សែវណ្ឌ និងខ្សែវណ្ឌគោល។
2. អានរូបរាងដីពីខ្សែវណ្ឌ៖ ភ្នំ ជ្រលង ជួរភ្នំ កំពូលរាប និងភាពចោត។
3. គណនាជម្រាលជាភាគរយ និងគូសផ្នែកកាត់បញ្ឈរ។
4. អានលេខយោងក្រឡា ៤ ខ្ទង់ និង ៦ ខ្ទង់ ពីក្រឡា UTM។
5. អានព័ត៌មាននៅគែមផែនទីទីសណ្ឋាន៖ ដាតុម ចន្លោះខ្សែវណ្ឌ លេខសន្លឹក។

## ៥.២. ស្ថានភាពបើកមេរៀន៖ ផ្លូវណាដែលឡានដឹកទំនិញអាចឡើងបាន?

ក្រុមស្ថាបនាមួយត្រូវដឹកសម្ភារៈទៅភូមិមួយនៅជើងភ្នំក្នុងខេត្តកំពង់ស្ពឺ។ មានផ្លូវពីរ៖ ផ្លូវខ្លីឆ្លងកាត់ជម្រាល និងផ្លូវវែងជាងវាងជុំវិញ។ ឡានដឹកទំនិញឡើងបានលុះត្រាតែជម្រាលក្រោម ១០%។

លើផែនទីទីសណ្ឋាន ១ : ៥០ ០០០ ផ្លូវខ្លីឆ្លងកាត់ខ្សែវណ្ឌ ១០ ខ្សែ ក្នុងចម្ងាយ ១ គីឡូម៉ែត្រ។ តើនោះជាជម្រាលប៉ុន្មាន?

សំណួរដែលមេរៀននេះឆ្លើយ៖

- ខ្សែវណ្ឌប្រាប់អ្វី ហើយអានយ៉ាងដូចម្ដេច?
- គណនាជម្រាលពីផែនទីដោយរបៀបណា?
- របៀបប្រាប់ទីតាំងឲ្យក្រុមផ្សេងតាមរយៈលេខយោងក្រឡា?

## ៥.៣. ទ្រឹស្ដីស្នូល

### ៥.៣.១. ផែនទីទីសណ្ឋាន

**ផែនទីទីសណ្ឋាន** បង្ហាញទាំងវត្ថុធម្មជាតិ និងវត្ថុមនុស្សបង្កើត ព្រមទាំងកម្ពស់។ វាត្រូវបានផលិតជាស៊េរីសន្លឹកតាមមាត្រដ្ឋានស្តង់ដារ។ នៅកម្ពុជា មាត្រដ្ឋានដែលប្រើញឹកញាប់គឺ **១ : ៥០ ០០០** និង **១ : ១០០ ០០០**។

ព័ត៌មាននៅ **គែមផែនទី (Map margin)** ដែលត្រូវអានមុនប្រើ៖

| ព័ត៌មាន | ហេតុអ្វីសំខាន់ |
|---|---|
| លេខ និងឈ្មោះសន្លឹក | រកសន្លឹកជាប់គ្នា |
| មាត្រដ្ឋាន និងរបារមាត្រដ្ឋាន | វាស់ចម្ងាយ |
| ចន្លោះខ្សែវណ្ឌ | គណនាកម្ពស់ និងជម្រាល |
| ដាតុម និងចំណោល | ភ្ជាប់ជាមួយ GPS និង GIS ([មេរៀនទី២](lesson-02.md)) |
| ក្រឡាកូអរដោនេ | អានលេខយោងក្រឡា |
| ឆ្នាំផលិត និងឆ្នាំកែ | ទិន្នន័យចាស់ប៉ុណ្ណា |
| សញ្ញាសម្គាល់ផែនទី | អត្ថន័យនៃនិមិត្តសញ្ញា |

!!! warning "ផែនទីចាស់"
    ផែនទីទីសណ្ឋានជាច្រើននៅតំបន់នេះត្រូវបានផលិតជាច្រើនទសវត្សរ៍មុន។ រូបរាងភ្នំមិនប្ដូរទេ ប៉ុន្តែផ្លូវ ភូមិ អាងទឹក និងព្រំដែនរដ្ឋបាល ប្ដូរច្រើន។ ត្រូវអានឆ្នាំផលិតជានិច្ច។

### ៥.៣.២. ខ្សែវណ្ឌ

**ខ្សែវណ្ឌ (Contour line)** ភ្ជាប់ចំណុចដែលមានកម្ពស់ស្មើគ្នា។ **ចន្លោះខ្សែវណ្ឌ (Contour interval)** គឺជាភាពខុសគ្នានៃកម្ពស់រវាងខ្សែពីរជាប់គ្នា ឧទាហរណ៍ ២០ ម។ **ខ្សែវណ្ឌគោល (Index contour)** គូសក្រាស់ជាង ហើយមានលេខកម្ពស់ ជាធម្មតារៀងរាល់ ៥ ខ្សែ។

<figure markdown>
--8<-- "assets/svg/c05-contours.svg"
<figcaption>រូបទី៥.១៖ ក្បួនអានខ្សែវណ្ឌ៖ រូបរាងខ្សែប្រាប់ពីភ្នំ ជ្រលង ជួរភ្នំ និងភាពចោត។ V នៃខ្សែវណ្ឌឆ្លងកាត់ស្ទឹង ចង្អុលទៅដើមទឹកជានិច្ច។</figcaption>
</figure>

ក្បួនសំខាន់៖ **V នៃខ្សែវណ្ឌដែលឆ្លងកាត់ស្ទឹង ចង្អុលទៅដើមទឹក** (ទៅតំបន់ខ្ពស់)។ នេះជាវិធីលឿនបំផុតដើម្បីបែងចែកជ្រលង និងជួរភ្នំលើផែនទី។

### ៥.៣.៣. ជម្រាល និងផ្នែកកាត់បញ្ឈរ

**ជម្រាល (Slope)** = កម្ពស់ឡើង ÷ ចម្ងាយផ្ដេក។

- ជាភាគរយ៖ (Δh ÷ d) × ១០០
- ជាដឺក្រេ៖ arctan(Δh ÷ d)

ឧទាហរណ៍៖ ឆ្លងកាត់ខ្សែវណ្ឌ ១០ ខ្សែ ដែលមានចន្លោះ ២០ ម ក្នុងចម្ងាយផ្ដេក ១ ០០០ ម → Δh = ២០០ ម → ជម្រាល = ២០០ ÷ ១ ០០០ = **២០%** (ប្រហែល ១១°)។

**ផ្នែកកាត់បញ្ឈរ (Profile)** គឺជាក្រាបកម្ពស់តាមបណ្ដោយខ្សែមួយ។ វាបង្ហាញភាពចោត ការឡើងចុះ និងថាតើមើលឃើញពីចំណុច A ទៅ B ឬអត់ (Line of sight)។

!!! example "ពិសោធន៍៖ ខ្សែវណ្ឌ និងផ្នែកកាត់បញ្ឈរ"
    ប្ដូរចន្លោះខ្សែវណ្ឌ ហើយសង្កេតថាផែនទីក្លាយជាលម្អិត ឬសាមញ្ញ។ អូសចំណុច A និង B ឆ្លងកាត់កំពូលភ្នំ ដើម្បីមើលផ្នែកកាត់បញ្ឈរ និងជម្រាល។ កម្ពស់ក្នុងគំរូនេះជាតម្លៃសំយោគសម្រាប់បង្រៀន។

### ៥.៣.៤. លេខយោងក្រឡា

ផែនទីទីសណ្ឋានមាន **ក្រឡាកូអរដោនេ (Grid)** ដែលជាធម្មតាជាក្រឡា UTM រៀងរាល់ ១ ឬ ២ គីឡូម៉ែត្រ។ **លេខយោងក្រឡា (Grid reference)** ជាវិធីខ្លីប្រាប់ទីតាំង ដោយប្រើតែខ្ទង់សំខាន់ៗនៃកូអរដោនេ។

<figure markdown>
--8<-- "assets/svg/c05-gridref.svg"
<figcaption>រូបទី៥.២៖ ការអានលេខយោងក្រឡាពីក្រឡាកូអរដោនេ UTM។ លេខយោង ៦ ខ្ទង់កំណត់ទីតាំងក្នុងចន្លោះ ១០០ ម៉ែត្រ។</figcaption>
</figure>

ក្បួន **«ស្ដាំមុន ឡើងក្រោយ» (Eastings first, Northings second)**៖

| ចំនួនខ្ទង់ | ភាពច្បាស់ | ឧទាហរណ៍ |
|---|---|---|
| ៤ ខ្ទង់ | ១ ០០០ ម | `05 55` |
| ៦ ខ្ទង់ | ១០០ ម | `052 554` |
| ៨ ខ្ទង់ | ១០ ម | `0520 5540` |

!!! tip "ភាពច្បាស់ និងភាពត្រឹមត្រូវ"
    លេខយោង ៨ ខ្ទង់មានភាពច្បាស់ ១០ ម ប៉ុន្តែផែនទី ១ : ៥០ ០០០ មានភាពត្រឹមត្រូវប្រហែល ២៥ ម ([មេរៀនទី៧ សៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/lessons/lesson-07/))។ កុំរាយការណ៍ភាពច្បាស់ ដែលទិន្នន័យមិនអាចទ្រទ្រង់។

### ៥.៣.៥. ការបង្ហាញរលកដីបែបផ្សេង

ក្រៅពីខ្សែវណ្ឌ រូបរាងដីអាចបង្ហាញដោយ៖

| វិធី | គុណសម្បត្តិ | គុណវិបត្តិ |
|---|---|---|
| **ខ្សែវណ្ឌ** | អានកម្ពស់ជាលេខបាន | អានរូបរាងពិបាកសម្រាប់អ្នកចាប់ផ្ដើម |
| **ស្រមោលភ្នំ (Hillshade)** | មើលឃើញរូបរាងភ្លាមៗ | អានកម្ពស់ជាលេខមិនបាន |
| **ពណ៌តាមកម្ពស់ (Hypsometric tints)** | បង្ហាញកម្រិតកម្ពស់ | ត្រូវការសញ្ញាសម្គាល់ច្បាស់ |
| **ក្រាបផ្នែកកាត់** | បង្ហាញភាពចោតតាមខ្សែ | មួយខ្សែក្នុងមួយរូប |

ការបញ្ចូលខ្សែវណ្ឌលើស្រមោលភ្នំ ជាការអនុវត្តល្អបំផុតលើផែនទីទំនើប។ ការគណនាស្រមោលភ្នំ និងជម្រាលពី DEM ជាខ្លឹមសារ[មេរៀនទី១៣ សៀវភៅទី២](https://khgeo.github.io/gis-fundamentals/lessons/lesson-13/) ឯមេរៀននេះផ្ដោតលើ **ការអាន និងការបង្ហាញ**។

## ៥.៤. ឧទាហរណ៍ដែលបានដោះស្រាយ៖ ផ្លូវណាដែលឡានឡើងបាន?

ផែនទី ១ : ៥០ ០០០ ចន្លោះខ្សែវណ្ឌ ២០ ម។ ផ្លូវ ក ខ្លី ឆ្លងកាត់ជម្រាល · ផ្លូវ ខ វែងជាង វាងជុំវិញ។

### ជំហានទី១៖ រាប់ខ្សែវណ្ឌ

ផ្លូវ ក ឆ្លងកាត់ខ្សែវណ្ឌ ១០ ខ្សែ រវាងកម្ពស់ ៦០ ម និង ២៦០ ម → Δh = ២០០ ម។

### ជំហានទី២៖ វាស់ចម្ងាយផ្ដេក

លើផែនទី ២ សម → ២ × ៥០ ០០០ = ១ ០០០ ម។

### ជំហានទី៣៖ គណនាជម្រាល

ជម្រាល = ២០០ ÷ ១ ០០០ = ០,២០ = **២០%** ≈ ១១,៣° ។ លើសដែនកំណត់ ១០%។

### ជំហានទី៤៖ ពិនិត្យផ្លូវ ខ

ផ្លូវ ខ ឡើងកម្ពស់ដដែល ២០០ ម ប៉ុន្តែវែង ៥,៥ សម → ២ ៧៥០ ម → ជម្រាល = ២០០ ÷ ២ ៧៥០ = **៧,៣%**។ ផ្លូវនេះសមស្របសម្រាប់ឡានដឹកទំនិញ។

### ជំហានទី៥៖ ប្រាប់ទីតាំងជុំ

ចំណុចជួបនៅលើផ្លូវ ខ មានលេខយោងក្រឡា ៦ ខ្ទង់ `052 554` ដែលកំណត់ទីតាំងក្នុងចន្លោះ ១០០ ម។

### សេចក្ដីសន្និដ្ឋានដែលសមស្រប

> «ផ្លូវ ក មានជម្រាលមធ្យម ២០% ដែលលើសដែនកំណត់ ១០% ឯផ្លូវ ខ មានជម្រាលមធ្យម ៧,៣% ដូច្នេះក្រុមការងារគួរជ្រើសផ្លូវ ខ ទោះវែងជាងជិត ៣ ដង។»

!!! warning "អ្វីដែលយើងមិនអាចសន្និដ្ឋាន"
    ជម្រាលមធ្យមមិនប្រាប់ពីចំណុចចោតបំផុតទេ។ ផ្លូវ ខ អាចមានផ្នែកខ្លីមួយចោត ១៥% ដែលលាក់ក្នុងតម្លៃមធ្យម។ ត្រូវពិនិត្យផ្នែកកាត់បញ្ឈរ ឬចន្លោះខ្សែវណ្ឌតូចបំផុត។ ផែនទីក៏មិនប្រាប់ពីស្ថានភាពផ្ទៃផ្លូវ និងស្ពានដែរ។

## ៥.៦. ការយល់ច្រឡំដែលត្រូវប្រុងប្រយ័ត្ន

**១. «ខ្សែវណ្ឌជាផ្លូវ ឬព្រំដែន»**
ខ្សែវណ្ឌជាខ្សែស្មើកម្ពស់ ដែលមិនមាននៅលើដីពិតទេ។

**២. «ខ្សែវណ្ឌអាចកាត់គ្នា»**
ចំណុចមួយមានកម្ពស់តែមួយ ដូច្នេះខ្សែវណ្ឌមិនកាត់គ្នាទេ លើកលែងករណីច្រាំងឈរបញ្ឈរ ដែលគូសដោយសញ្ញាពិសេស។

**៣. «V នៃខ្សែវណ្ឌចង្អុលតាមទិសទឹកហូរ»**
V ចង្អុលទៅ **ដើមទឹក** ពោលគឺផ្ទុយពីទិសទឹកហូរ។

**៤. «ជម្រាល ១០០% ស្មើ ៩០°»**
ជម្រាល ១០០% មានន័យថាឡើង ១ ម ក្នុងចម្ងាយផ្ដេក ១ ម ពោលគឺ ៤៥°។

**៥. «លេខយោង ៨ ខ្ទង់ ត្រឹមត្រូវ ១០ ម»**
វាមានភាពច្បាស់ ១០ ម ប៉ុន្តែភាពត្រឹមត្រូវអាស្រ័យលើផែនទី ដែលអាចត្រឹម ២៥ ម ឬអាក្រក់ជាង។

### ខ. ការភ្ជាប់ទៅមេរៀនបន្ទាប់

យើងបានអានផែនទីដែលអ្នកផ្សេងធ្វើរួច។ ចាប់ពីមេរៀនបន្ទាប់ យើងចាប់ផ្ដើម **រចនា** ផែនទីដោយខ្លួនឯង។ ចូរបញ្ចប់ដោយបង្ហាញសញ្ញាចំណុចពីរបែប (រង្វង់ធំតូច និងពណ៌ខុសគ្នា) សម្រាប់ទិន្នន័យដដែល ហើយសួរ៖

> «ហេតុអ្វីសញ្ញាមួយប្រាប់ «ច្រើនជាង» ឯសញ្ញាមួយទៀតប្រាប់តែ «ខុសគ្នា»?»

សំណួរនេះនាំទៅ [**មេរៀនទី៦៖ អថេរមើលឃើញ និងការរចនានិមិត្តសញ្ញា**](lesson-06.md)។
