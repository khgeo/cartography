# មគ្គុទ្ទេសក៍វាលទី២៖ GPS/GNSS និងការប្រមូលទិន្នន័យ

ឧបករណ៍ដែលអ្នកប្រើហៅថា GPS ជាទូទៅជាអ្នកទទួលសញ្ញា GNSS។ វាគណនាទីតាំងពីចម្ងាយទៅផ្កាយរណប មិនមែនបញ្ជូនផ្លូវពីផ្កាយរណបមកជាផែនទីរួចស្រេចទេ។ លទ្ធផលល្អអាស្រ័យលើបរិយាកាស ការកំណត់ឧបករណ៍ និងវិធីកត់ត្រា។

## ១. ប្រព័ន្ធបីផ្នែក

- **ផ្នែកអវកាស**៖ ក្រុមផ្កាយរណបផ្សាយពេលវេលា និងគន្លង។
- **ផ្នែកគ្រប់គ្រង**៖ ស្ថានីយតាមដាន និងកែទិន្នន័យគន្លង/នាឡិកា។
- **ផ្នែកអ្នកប្រើ**៖ ឧបករណ៍ទទួល ឬទូរស័ព្ទ គណនាទីតាំង និងរក្សាទុកវត្ថុ។

ទីតាំងផ្ដេកត្រូវការធរណីមាត្រផ្កាយរណបល្អ។ ជ្រលង ជញ្ជាំង ក្រោមដំបូលដែក និងក្រោមព្រៃក្រាស់អាចបិទ ឬឆ្លុះសញ្ញា។ លេខ accuracy លើអេក្រង់ជាការប៉ាន់ស្មាន មិនមែនការធានា។

## ២. Checklist មុនចុះវាល

1. សាកថ្ម និងយកថ្ម/Power bank បម្រុង។
2. កំណត់ **position format** និង **datum** ឱ្យដូចផែនទី/គម្រោង; សម្រាប់ករណីភាគច្រើន WGS 84 និង UTM zone 48N ឬភាគច្រើននៃកម្ពុជា។ តំបន់ខាងកើតខ្លះអាចស្ថិត zone 49N ដូច្នេះត្រូវពិនិត្យទីតាំង។
3. កំណត់ឯកតាម៉ែត្រ និងពេលវេលាត្រឹមត្រូវ។
4. សម្អាត memory តែបន្ទាប់ពីបម្រុងទុក។
5. រៀបចំលេខសម្គាល់ដូច `SCH-001`, `WAT-001`; ឈ្មោះកុំឱ្យស្ទួន។
6. បោះពុម្ព/រក្សាទុក data dictionary និងទម្រង់កត់ត្រាវាល។
7. នៅទីចំហ រង់ចាំ position fix និងស្ថេរភាពមុនចាប់ផ្ដើម។

## ៣. Waypoint, track និង route

| វត្ថុ | ប្រើសម្រាប់ | ច្បាប់គុណភាព |
|---|---|---|
| Waypoint | អណ្ដូង សាលារៀន ចំណុចគំរូ | រង់ចាំ, average បើអាច, កត់លេខសម្គាល់ |
| Track | ផ្លូវ ព្រំដែន ផ្លូវទឹក | កំណត់ interval សមរម្យ; ចាប់/ផ្អាកត្រឹមកន្លែង |
| Route | ផែនការធ្វើដំណើរ | ពិនិត្យភាពអាចឆ្លងបាននៅវាល |

## ៤. Data dictionary និងសៀវភៅវាល

ទិន្នន័យទីតាំងមួយគ្មានតម្លៃគ្រប់គ្រាន់ បើគ្មានអត្ថន័យ។ សម្រាប់អណ្ដូងទឹក អាចកំណត់វាល `id`, `type`, `status`, `depth_m`, `water_on_date`, `photo_id`, `collector`, `timestamp`, `accuracy_m`, `notes`។ កំណត់តម្លៃអនុញ្ញាតជាមុន ដើម្បីកាត់បន្ថយអក្ខរាវិរុទ្ធខុស។

!!! example "ការវាស់ចំណុចតែមួយបីដង"
    វាស់សញ្ញាគោលដដែលនៅពេលមកដល់ កណ្ដាលថ្ងៃ និងមុនត្រឡប់។ បើចំណុចរាលខ្លាំងជាង accuracy ដែលបានកត់ នោះការបិទបាំងសញ្ញា ឬការកំណត់ខុសអាចមានបញ្ហា។ កុំជ្រើសតែចំណុចដែល «មើលទៅត្រូវ»; រក្សាទុកការវាស់ទាំងអស់សម្រាប់ពិនិត្យ។

## ៥. នីតិវិធីនៅចំណុចនីមួយៗ

ឈរ​នៅ​កន្លែងតំណាង → ពិនិត្យ ID → រង់ចាំ fix → average → save waypoint → បំពេញ attribute → ថតរូបដែលមានលេខដូច ID → អានឡើងវិញឱ្យដៃគូផ្ទៀងផ្ទាត់។ សម្រាប់ track ត្រូវសរសេរពេលចាប់/ឈប់ និងមូលហេតុនៃចន្លោះ។

## ៦. បន្ទាប់ពីវាល និង QGIS

1. ចម្លង raw file ដោយមិនកែ និងបង្កើត working copy។
2. Export ទៅ GPX/CSV/GeoJSON តាមដែលឧបករណ៍គាំទ្រ។
3. ក្នុង QGIS បញ្ជាក់ CRS ប្រភពត្រឹមត្រូវ; កុំប្រើ “Assign CRS” ដើម្បីបម្លែងលេខ។
4. ពិនិត្យចំណុចលើ imagery/ផែនទីយោង ប៉ុន្តែកុំផ្លាស់ទីដោយស្វ័យប្រវត្តិតាមរូបភាពដែលអាចលំអៀង។
5. ស្វែងរក ID ស្ទួន កូអរដោនេ 0,0, ទីតាំងក្រៅតំបន់ និង attribute ខ្វះ។
